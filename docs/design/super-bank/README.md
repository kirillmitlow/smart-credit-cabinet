# Super-Bank: утверждённый дизайн

Эталон внешнего вида кабинета (D-113, 26.10). Направление «Контраст»: графитовая шапка, серый фон, белые карточки без рамок, кнопки-«таблетки», красный акцент. Выбрано пользователем после двух раундов правок; прежние направления — в `../mockups/stage1/`.

## Что здесь

| Папка | Что |
|---|---|
| `png/` | Картинки экранов шириной 1440 px; `00-obzor.png` — все экраны на одном листе |
| `html/` | Те же экраны страницами HTML для сверки отступов и цветов. Шрифты в них грузятся из Google Fonts, в приложении — локально |

Экраны: вход (три шага), главная, мастер подбора, результат подбора, заявка с тремя вариантами (СнабКонтракт), подписание (Соколова), карточка заявки для банка (СтанкоПром).

## Токены

Все цвета, шрифты и радиусы — в `web/src/app/theme.ts`, экраны берут их оттуда.

| Токен | Значение |
|---|---|
| Акцент | `#D7262E`, наведение `#B8141B`, на тёмном — `#FF8A8D` |
| Графит (шапка, тёмные карточки) | `#17171A`, вторичный тёмный `#27272A` |
| Фон страницы | `#EEEEF0`, карточки белые |
| Приглушённый текст | `#52525B` (на белом и сером ≥ 4,5:1) |
| Шрифты | заголовки Unbounded, текст Onest (`@fontsource-variable`, без сети) |
| Радиусы | карточки 16 px, поля 12 px, кнопки — «таблетка» |

## Правила переноса

- Тексты экранов — только из `web/src/texts/`; макет показывает тон, а не обязательные формулировки.
- Числа в макетах взяты из 30-16 и 30-17; в приложении они приходят с сервера.
- Пиксель в пиксель не требуется: сверяем структуру, иерархию и цвета.
