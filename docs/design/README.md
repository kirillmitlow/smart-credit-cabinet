# Макеты интерфейса

Здесь лежат статические макеты «Умного кредитного кабинета»: по ним команда выбирает внешний вид до написания экранов (D-059, D-087, процесс — [60-07](../plan/60-frontend/07-mockups.md)). Это не рабочий код: на выбранной библиотеке (Mantine, D-085) экраны будут написаны заново.

## Как открыть

Двойным щелчком откройте `mockups/stage1/index.html` — это галерея с превью и ссылками. Каждая страница самодостаточна: стили внутри, шрифты системные, ничего не грузится из сети, сборка не нужна. Лучше смотреть в браузере на ширине 1280–1440 px (телефон не поддерживаем, D-063).

## Что в папке

| Файл | Что это |
|---|---|
| `mockups/stage1/index.html` | Галерея: 6 превью, описание направлений, вопросы для выбора |
| `mockups/stage1/bank-home.html`, `bank-timeline.html` | Направление 1, «Строгий банк»: светлое, плотное, табличное |
| `mockups/stage1/friendly-home.html`, `friendly-timeline.html` | Направление 2, «Дружелюбный финтех»: тёплое, крупные карточки, эмодзи |
| `mockups/stage1/dark-home.html`, `dark-timeline.html` | Направление 3, «Тёмный профессиональный»: тёмная тема, боковая панель, моноширинные цифры |

Два экрана этапа 1 по [60-07](../plan/60-frontend/07-mockups.md): **«Главная»** и **«Страница заявки с таймлайном»**. Героиня — ООО «СнабКонтракт» (запрос 8 млн ₽ на 12 месяцев, платёж 744 910 ₽). На странице заявки в блоке исхода показаны три встречных предложения и блок «Как получить то, что просили» (30-10, 60-03 экран 10). На главной показана подсказка помощника «Похоже, вы … — верно?» с подтверждением (D-094). Числа взяты из [30-16](../plan/30-decisioning/16-loan-math.md).

## Что общее у всех направлений

- Нейтральное название «Умный кредитный кабинет», красный акцент (D-085), без логотипа и названия банка.
- Постоянная плашка «Демо-прототип. Все данные синтетические» над шапкой.
- «Откуда?» у данных из внешних источников (D-085), подсказки к терминам по наведению и Tab (60-06).
- Тексты по [60-06](../plan/60-frontend/06-ux-writing.md): «на вы», без внутренних кодов и баллов.
- Контраст текста не ниже 4,5:1, основной текст от 14 px.
- Цвета, радиусы и шрифт заданы переменными CSS в начале `<style>` каждой страницы: это заготовка токенов темы Mantine.

## Как выбирается направление

1. Пользователь открывает галерею и отвечает на пять вопросов в конце страницы: какое надёжнее, понятнее новичку, приятнее, серьёзнее для банка, удобнее для работы.
2. Ответ: «направление N» или «N, но акцент из M».
3. Этап 2 ([60-07](../plan/60-frontend/07-mockups.md)): остальные экраны (вход, мастер и результат подбора, заявка с таймлайном, встречные, карточка банка) и состояния в выбранном направлении, в `docs/design/<направление>/`.
4. После явного «да» пользователя макеты фиксируются, переменные уходят в файл темы библиотеки. Сам HTML в реализацию не переносится.

Не выбранные направления остаются в репозитории как след процесса и в дальнейшем не развиваются.
