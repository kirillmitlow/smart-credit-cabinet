# Сценарии проверки для жюри

Пошаговые действия с названиями кнопок — в [README, «Самопроверка»](../README.md#самопроверка-за-2030-минут). Здесь — карта ожидаемых исходов и доказательств, сверенная с main `1114d1c` 24.10.2026. Условия синтетические, выдача имитируется.

Перед повтором сбросьте **нужную персону** в `/demo`: это удалит её демо-заявки и кредиты. Общий сброс влияет на всех. Коды входа, согласий и договора берите с экрана или из свежего ответа API; постоянного кода нет. Для повторяемости числа проверяются при `APP_TODAY=2026-10-21`. Порт web по умолчанию 8080, на отдельной установке команды — 8090.

Для Соколовой оракул: 21,5% годовых, 46 677 ₽ ежемесячно, последний платёж 46 679 ₽. В мастере предварительный платёж может отличаться; итог берётся из решения. Для ручного встречного Станкопрома ставку и ограничения считает сервер, не подставляйте её из другого продукта.

Дополнительный проверенный банком путь: запросить **текстовое пояснение**, сохранить/отправить ответ, дождаться повторной проверки, затем принять решение. Это [TS-032](../web/e2e/bank-actions.spec.ts); он не доказывает работу загрузки документа. В оборотной папке Postman запрос пояснения не вставлен: она проверяет прямой ручной расчёт и сохранение.

## Что именно доказывают проверки

- [Отчёт комплекта 24.10](plan/reviews/C-2026-10-24-jury-package-refresh.md) — исполнение коллекции, проверка схем, ссылок и состава файлов. Прогон API не равен прохождению браузерного интерфейса.
- [Передача банка 23.10](plan/reviews/B-2026-10-23-bank-handoff.md) и [журнал](plan/00-meta/07-journal.md) — ранее выполненные браузерные проверки команды. Они сохраняют дату и контекст, а не выдаются за новый прогон всех тестов.
- Существующие TS-метки сохранены; новые номера для тех же сценариев не изобретались. Этот компактный каталог не закрывает полный T-528/T-523: автоматическая проверка всех меток и полный каталог технических ветвей остаются в плане.
- Полный прогон Postman в GUI, чистая Windows и чтение README новым человеком требуют отдельной проверки; импорт формата инструментом исполнения не заменяет эти действия.
