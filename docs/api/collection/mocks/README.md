# Запросы к мокам

Открыть эту папку как коллекцию Bruno. В окружении задать `scenariosUrl` (`http://127.0.0.1:8105`) и `mockAdminKey` (локальный ключ из README репозитория; в облаке свой).

`own-company/preview-llc.bru` возвращает `200`: блоки `identity` и `registry`, владелец — второй учредитель с долей 60%. Два одинаковых запроса при той же дате и занятых ИНН дают одинаковое тело. Данные не сохраняются.

`own-company/preview-missing-form.bru` возвращает `422 VALIDATION_ERROR`: нужны `preset` или `company.form` (D-101).

Предпросмотр уже разворачивает реквизиты, финансы, БКИ и остальные системы (T-120…T-126).

`own-company/create-ip.bru` создаёт `jury-custom` и записывает его во все нужные моки:
`201`, статус APPLIED, журнал в applications. Повтор с тем же ключом возвращает тот же ответ.

`own-company/apply-one.bru` возвращает эту компанию в исходное состояние (`200`),
включая удаление выдач и запросов БКИ. У других компаний данные сохраняются.
При сбое — `502 APPLY_FAILED`; подробности и итог отката видны в GET сценария.

Полная коллекция всех ролей — T-140. Bruno CLI пока не подключён;
эти HTTP-сценарии проверяются интеграционными pytest.
