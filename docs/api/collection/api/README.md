# Запросы к API кабинета

Открыть папку как коллекцию Bruno. Переменные окружения: `apiUrl` (например, `http://127.0.0.1:8088/api/v1` через web), `companyId`, `sidClient` (cookie `sid_client` после демо-входа). Значения сессии не сохранять в Git.

[Список госконтрактов](companies/gov-contracts.bru): `200`, `items`, `nextCursor`, источник ЕИС и дата получения. Для `snabkontrakt` действующий контракт на 12 млн рублей. Чужая компания или роль поручителя — `404`; сбой источника без действующего кэша — `503 SERVICE_UNAVAILABLE`.

Bruno CLI пока не подключён (T-140); сценарий проверен интеграционными и контрактными pytest.
