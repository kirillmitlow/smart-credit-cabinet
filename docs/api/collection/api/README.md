# Запросы к API кабинета

Открыть папку как коллекцию Bruno. Переменные окружения: `apiUrl` (например, `http://127.0.0.1:8088/api/v1` через web), `companyId`, `companyInn`, `sidClient` (cookie `sid_client` после демо-входа). Значения сессии не сохранять в Git.

[Обновить по ИНН](companies/lookup.bru): `200`, карточка из реестра, налоговой и банка с `source`, `retrievedAt`, `confirmed` для каждого поля. Для примера Соколовой `companyInn=001234567887`.

[Получить карточку компании](companies/get-profile.bru): `200`, используется кэш до 24 часов. `companyId` берётся из `GET /me` после входа. Чужая компания или роль поручителя — `404`, неавторизованный запрос — `401`. При DOWN источника карточка остаётся доступной, его поля неподтверждённые. Более 30 обращений в минуту на сессию — `429` с `Retry-After`.

[Список госконтрактов](companies/gov-contracts.bru): `200`, `items`, `nextCursor`, источник ЕИС и дата получения. Для `snabkontrakt` действующий контракт на 12 млн рублей. Чужая компания или роль поручителя — `404`; сбой источника без действующего кэша — `503 SERVICE_UNAVAILABLE`.

Bruno CLI пока не подключён (T-140); эти сценарии проверены интеграционными и контрактными pytest.

[Решение сотрудника](bank/decision.bru): сначала [вход банка](bank/login.bru), затем карточка `GET /backoffice/applications/{id}`. Из неё взять `applicationId`, `applicationVersion`, `engineDecisionId`; `decisionActionKey` — новый ключ действия. Пример одобряет Станкопром на 15 млн / 60 месяцев. `ratePercent` можно не передавать: ставку определит ядро; при передаче единица — проценты (19.5, не 0.195). Для отказа `outcome=REJECTED`, `terms=null`; при отклонении от рекомендации нужны `reasonCode` и комментарий. Проверка ядра действует и при ручном вводе условий. Повтор того же тела с тем же ключом возвращает тот же `decisionId` и `Idempotent-Replayed: true`; другой запрос с этим ключом — 409. Устаревшая версия — 409, недостаточные полномочия — 403 с аудитом, недопустимые условия — 422. Внутренний комментарий не включается в клиентское решение.

[Сбросить одну персону](demo/reset-persona.bru): `personaCode=sokolova`, ответ 200 после завершения всех шагов. Не требует входа в локальном демо; сохраняет сессию. Занятая операция — 409, частичный сбой — 502 с названием шага; повторить тот же запрос. Вне DEMO_MODE — 403.

[Запросить пояснение](bank/request-info.bru): L1/L2, обязательны версия, причина и от1до10 задач. Ответ200: NEEDS_INFO, номер раунда и taskIds. Четвёртый раунд409 ROUNDS_LIMIT_REACHED. Карточка банка показывает clientTasks и latestAnsweredRound; текст и автор черновика скрыты до отправки раунда клиентом.

[Перепроверить](bank/recheck.bru): L1/L2, версия и новый ключ действия. Ответ200: CHECKING и runId; запуск ставится после commit. Повтор того же ключа не создаёт второй запуск. Свежий БКИ используется повторно. Для каждого нового действия брать актуальную версию из карточки.
