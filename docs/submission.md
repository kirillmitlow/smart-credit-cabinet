## Что вставить в форму сдачи

- Проект: **Умный кредитный кабинет предпринимателя**.
- Репозиторий: <https://github.com/kirillmitlow/smart-credit-cabinet>.
- Версия: тег `submission-20261026-2`. Полный SHA: `git rev-parse 'submission-20261026-2^{commit}'` после `git fetch origin --tags`. Именно полученный SHA скопировать в поле версии.
- Точка входа: [README](../README.md).
- Продуктовая логика, границы MVP, формулы и Roadmap: [обоснование](product-rationale-and-roadmap.md).
- Схемы, API, коллекции и лицензии: [навигатор](README.md).
- Проверки и их ограничения: [отчёт 25.10](plan/reviews/B-2026-10-25-freeze-verification.md).
- Облачная ссылка: **пока отсутствует**; воспроизводимый Docker-запуск описан в README.

Краткое описание для формы:

> Прототип цифрового кредитного конвейера для малого бизнеса: подбор продукта, автозаполнение по ИНН, сбор данных из смоделированных источников, детерминированная оценка риска и небинарное кредитное решение, ручное рассмотрение банком, подписание и демонстрационная выдача с графиком платежей. Проверены четыре основных браузерных сценария: автоодобрение, автоматическое встречное предложение, ручное встречное предложение и мотивированный отказ. Все данные и интеграции синтетические; подписи и выдача не имеют юридической силы.

Проверять выбранную версию можно в отдельном чистом клоне через `git checkout --detach submission-20261026-2`. В рабочей папке с незакоммиченными правками этого не делать. Дату `APP_TODAY`, порты и входы взять из README выбранного тега.
