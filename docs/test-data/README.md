[garipov-statement-12-months.txt](garipov-statement-12-months.txt) — синтетическая выписка 1С 1.03, Windows-1251, ИНН Гарипова `001298765490`. Период 01.10.2025–30.09.2026: 12 полных месяцев, в каждом 700 000 ₽ входящих и 600 000 ₽ исходящих; начальный остаток 0, конечный 1 200 000 ₽.

Файл получен без парсера и мок-генератора существующим независимым writer из [test_statement_source.py](../../api/tests/integration/test_statement_source.py), функция statement() с параметрами по умолчанию, и [cases.py](../../api/tests/fixtures/statements/cases.py). Числа — из утверждённого оракула 30-17. Это тестовые данные проекта, не реальная выписка.

Используется при APP_TODAY=2026-10-21. Загрузите файл в задачу Гарипова как «Выписка по счёту», дождитесь разбора, проверьте суммы и отдельно подтвердите поступления. Подпись/выдача после повторного расчёта проверены по API; полный новый браузерный проход не выполнялся. Кнопка генерации не является источником этого файла: её мок пока недоступен (503 от API).
