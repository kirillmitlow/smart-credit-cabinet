## Три параллельных задания

Это предложение перераспределить A/C по просьбе пользователя руководить ускорением. Все API/миграции за пределами неё должны входить в пересланное пользователем поручение.

### B — закончить ручную работу банка

Задачи: **T-362, T-363, T-364, T-432, T-433, T-442**. Исходная оценка 34 часа, не новый прогноз времени.

- Зона: backoffice API, экраны bank; использовать публичные интерфейсы A, не менять policy и ядро.
- Первый небольшой PR: сохранить решение с правами L1/L2, expected_version, проверкой причины и защитой повторов. Следующие — запрос/перепроверка, ручной расчёт, экраны и сквозной тест.
- Приёмка: Станкопром → MANUAL_REVIEW → запрос пояснения → ответ клиента → перепроверка → решение сотрудника → предложение клиенту. Для документов дождаться публичного интерфейса C; текстовое пояснение не требует его.
- Не допускаются обход стоп-фактора, запись B в чужие таблицы, утечка служебного комментария клиенту, повторное создание решения на двойной клик.
- Проверки: полномочия, устаревшая версия, причина отклонения, откат, изоляция компаний, UI и T-442.

### C (второй Codex) — выписка и файловый путь Гарипова
