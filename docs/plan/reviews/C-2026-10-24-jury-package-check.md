## Что эта работа не подтверждает

- Новый браузерный прогон четырёх сценариев здесь не выполнялся. Исторические UI-проверки 23.10 остаются в журнале и передаче B. Postman GUI не открывался: формат принят Newman, не проверены действия пользователя в GUI.
- Не выполнялись чистая Windows, репетиция человеком не из разработки, нагрузка, хаос, выпуск, публикация образов, облако, новый полный `make test`. Полный `make check` локально в этой документационной смене не перезапускался; перед PR выполняются проверки документов, JSON, Mermaid и целевых файлов, CI документационного PR проверяется отдельно.
- Не проверены и не обещаны загрузка/разбор выписки, PDF, залог/поручитель, весь путь Гарипова или передача подписи бухгалтер → директор. Их доводит Codex №1. Текст не заменяет выписку.
- В API этого main нет выдачи/проверки CSRF-токена; фронт умеет его отправлять. Разрыв отражён в API-навигаторе и ранее открытом Q-146; документ не добавляет гарантий защиты.
- Диаграммы и перечень лицензий — проверенные снимки, автоматической актуализации в CI в этом пакете нет. T-524…T-527 и T-544 не объявлены полностью завершёнными по старым расширенным карточкам.
