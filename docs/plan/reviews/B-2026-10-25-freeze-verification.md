## Запуск

Отдельная рабочая копия, macOS / Apple Silicon / Docker Desktop. Стенд поднят **один раз**:

```bash
APP_TODAY=2026-10-21 WEB_PORT=8090 IMAGE_TAG=freeze-20261025 \
  docker compose -p scc-bank-actions up -d --build --wait
```

Результат: 12 сервисов; 10 контейнеров `healthy`, `beat` работает без healthcheck по Compose, разовый `db-init` — `Exited (0)`. Web отвечает на <http://127.0.0.1:8090>, API и пять моков — HTTP 200 на `/health/ready`. Все шесть живых `/openapi.json` совпали с сохранёнными схемами. Другие Docker-проекты не останавливались и не сбрасывались. Стенд оставлен для просмотра результатов; перед повтором сбрасывается только нужная персона.

8090 — выбранный порт этого стенда. По умолчанию Compose публикует web на **8080**, API и моки — **8100–8105**.

## Четыре контрольных пути

Все заявки создавались и отправлялись кликами в браузере Chromium. API использовался только для подготовки/сброса конкретной персоны. Коды брались с экрана, банковская сессия была отдельной. Условия и результаты не подставлялись через API.

| Персона | Ввод в интерфейсе | Подтверждённый результат |
|---|---|---|
| Соколова, `001234567887` | Каталог и калькулятор; мастер; EXPRESS, 500000 ₽ / 12 месяцев | Автоодобрение, 21,5%, 46677 ₽; принятие, подпись, выдача; график из 12 платежей |
| СнабКонтракт, `0012345673` | WORKING_CAPITAL, 8000000 ₽ / 12 месяцев | Автоматические встречные; выбран вариант 8000000 ₽ / 36 месяцев; подпись, выдача, 36 платежей |
| Станкопром, `0017654322`, Кузнецов | WORKING_CAPITAL, 15000000 ₽ / 12 месяцев | MANUAL_REVIEW; банк L2 рассчитал и сохранил 10000000 ₽ / 12 месяцев с расчётной ставкой, категорией и пояснением; клиент принял и подписал; выдача, 12 платежей |
| Ромашка, `0015557771` | WORKING_CAPITAL, 3000000 ₽ / 6 месяцев | REJECTED; на экране причины по налоговому долгу и кредитной просрочке, положительное предложение отсутствует |

Контроль не был запуском всего e2e-набора. Первые остановки временного runner были связаны с импортом/поиском полей, ожиданием нового сетевого ответа при уже готовом калькуляторе, неразрывными пробелами и полным доступным именем ссылки на кредит. При быстром заполнении также требовалось дождаться загрузки данных компании до согласий. Исправлялся runner, а не продукт. Повторялись только затронутые проверки; уже прошедшие Ромашка и каталог не повторялись.

Станкопром прошёл создание, ручное встречное, принятие и подпись до фактической выдачи в одном UI-проходе; старое ожидание текста остановило runner после выдачи. График затем проверен отдельным входом через интерфейс без повторной заявки или банковского решения. Соколова после исправления селектора прошла целый существующий TS-001, включая график. СнабКонтракт прошёл до графика после исправления временных селекторов. Эти границы сохранены в JSON, ранние остановки не переименованы в успешные тесты.

## Генератор выписки

- GET scenarios без `X-Admin-Key` — 401; с ключом — 200, файл Windows-1251 с CRLF, `Content-Disposition: attachment`, `X-Mock-Simulated: true`. Повтор GET дал одинаковые байты.
- При дате 2026-10-21 период Гарипова — 01.10.2025–30.09.2026: 12 полных месяцев по 700000 ₽ входящих / 600000 ₽ исходящих, остаток 0 → 1200000 ₽. Размер 335671 байт; SHA-256 `4f44b423281c86ef61dc429eb252a0b48065cf3467a248a3d5ccbfb5175ee8fc`.
- Неизменённый настоящий `parse_statement` подтвердил период и суммы. Ожидаемое `UNCLASSIFIED_RECEIPTS` сохраняет необходимость отдельного подтверждения бизнес-поступлений.
- Оба постоянных Postman-примера GET/POST генератора: **2 запроса / 8 проверок / 0 ошибок**.
- Дополнительный Гарипов по API: настоящий `POST /demo/bank-statement` → 201 / `DEMO_GENERATED` → PARSED → подтверждение → повторное одобрение → подпись → DISBURSED → график. **30 запросов / 51 проверка / 0 ошибок**. Это отдельная API-проверка, не пятый полный браузерный сценарий. Независимый готовый файл и его происхождение сохранены.

## Оставшиеся границы

Подтверждённых препятствий для запуска, этих четырёх путей и наличия обязательных материалов не обнаружено. Это не приёмка всего продукта: Windows, облако, нагрузка/длительные сбои, весь путь поручителя и бухгалтера заново не проверялись. Редкие случаи отзыва доступа из draft №140 остаются отдельными. Подписи и деньги демонстрационные; системные библиотеки и собственная лицензия описаны с прежними оговорками. Новостная лента исключена D-019 и не добавлялась.
