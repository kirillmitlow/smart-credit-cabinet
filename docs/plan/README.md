# План проекта

Все планы «Умного кредитного кабинета» лежат здесь. **Один файл — одна тема**: так агенты и люди меняют план по частям и не мешают друг другу.

## С чего начать

| Кто вы | Что прочитать |
|---|---|
| Пользователь (принимает решения) | [Как мы планируем](00-meta/01-planning-process.md), затем [открытые вопросы](00-meta/06-open-questions.md). Дальше только документы вариантов, которые помечены в [бэклоге](00-meta/04-planning-backlog.md) как «нужен выбор» |
| Агент, который начинает смену | [Протокол сменщиков](00-meta/03-collaboration-protocol.md): он обязателен. Потом [передача смены](00-meta/08-handoff.md), откуда продолжать. Потом [журнал](00-meta/07-journal.md), [решения](00-meta/05-decisions-index.md), [бэклог](00-meta/04-planning-backlog.md) |
| Тот, кто пишет новый документ | [Стандарт документов](00-meta/02-doc-standard.md) и [шаблоны](00-meta/templates/) |

## Карта папок

| Папка | О чём | Фаза |
|---|---|---|
| `00-meta/` | Как планируем: процесс, правила, бэклог документов, решения, вопросы, журнал, передача смены | 0 |
| `10-product/` | Требования кейса, персоны, роли, MVP, каталог продуктов, клиентский путь, лента | 1 |
| `20-process/` | Модель кредитного процесса, статусы заявки, задачи клиенту, согласия, выдача | 2 |
| `30-decisioning/` | **Кредитное решение**: данные, выручка, стоп-факторы, скоринг, ML, лимиты, ставка, встречные предложения, объяснения | 3 |
| `40-ai/` | ИИ и NLP: свободный текст, документы, лента, тексты для андеррайтера | 3 |
| `50-architecture/` | Стек, модули, данные, API, очереди, безопасность, наблюдаемость, деплой | 4 |
| `60-frontend/` | Структура фронта, дизайн-система, экраны, макеты | 5 |
| `70-quality/` | Тесты: pytest, свойства, синтетика, контракты, e2e, нагрузка, CI | 6 |
| `80-delivery/` | Атомарные задачи реализации, график, распределение, сдача, демо | 7 |
| `decisions/` | Принятые решения, по одному файлу на решение | все |

Папки создаются по мере работы. Полный список будущих документов и их статусы ведутся только в [бэклоге](00-meta/04-planning-backlog.md), здесь они не дублируются.
