Организаторы: ИИ сам по себе баллов не даёт, плюсом считается только конкретная польза клиенту или процессу (10-00, п. 4). Поэтому у нас ИИ мало, он на своём месте, и всё работает без него.

## Принципы

| № | Принцип | Что это значит на деле |
|---|---|---|
| 1 | **ИИ не принимает кредитных решений** (D-032) | Решение: детерминированное ядро `decide()` и правила. Модель не видит данных заявки и не влияет на сумму, ставку, исход. Продукт выбирает таблица правил |
| 2 | **У каждой ИИ-функции есть запасной путь** | Без модели интерфейс продолжает работать: кнопки, шаблоны, ручной ввод. Ошибка модели не показывается клиенту как ошибка |
| 3 | **Только открытые веса и свободные лицензии** (10-00, п. 13) | MIT или Apache-2.0. Модели с «условиями использования», запретом коммерции, доступом по заявке не берём, даже если можно скачать |
| 4 | **Работает на CPU** (D-066) | Офисный ПК, 8–16 ГБ, без видеокарты. Маленькие модели, ONNX, ответ быстрее 1–2 с |
| 5 | **Вшито в образ, без интернета при запуске** (D-058, D-094) | Веса скачиваются с Hugging Face при сборке образа (докачка и проверка хеша); в готовом публичном образе GHCR модель уже внутри; при запуске ничего не качается ([40-06](06-model-packaging-and-licenses.md)) |
| 6 | **Отдельный контейнер, включён по умолчанию** (D-094) | Контейнер `nlu` в профиле `ai`, который включён везде (локально и в облаке); входит в основной бюджет памяти (≤ 4 ГБ по лимитам ≈ 3,4 ГБ, [50-01](../50-architecture/01-overview.md)). Профили `ai` и `obs` вместе на ПК жюри не включаем |
| 7 | **Человек подтверждает** (D-094) | Ответы модели — только подсказки с подтверждением: клиент видит, где предложено, и подтверждает или правит. Ничего не уходит в заявку «молча» |
| 8 | **Ничего не уходит наружу** | Текст клиента обрабатывается в нашем контейнере. Облачных API и телеметрии нет |
| 9 | **Польза измерена** | Для каждой функции есть набор примеров и порог. Прошла порог — включаем, нет — остаётся запасной путь ([40-07](07-ai-evaluation.md)) |
| 10 | **Честно в интерфейсе и README** | Подсказка помечена («из вашего текста»), в README указано, что и зачем делает модель, сколько памяти ест |

Порог качества (40-00): **не менее 80% точности и ответ быстрее 1–2 с на CPU** для подсказок. Автоподстановку (≥ 95%) не включаем: T-001 дал 87,9% (см. [40-02](02-free-text-wizard-spec.md)).

## Чек-лист новой ИИ-функции

Функция попадает в продукт, только если на все пункты есть ответ:

1. Какую конкретную проблему клиента или банка решает ([10-04](../10-product/04-research-jtbd.md))?
2. Что происходит, если модель недоступна?
3. Как клиент видит и правит результат?
4. Чем измерено качество, какой порог?
5. Сколько памяти и секунд на CPU?
6. Лицензия модели и библиотек, добавлено ли в `THIRD_PARTY_NOTICES`?
7. Как выключить одной настройкой?
8. Не влияет ли она на кредитное решение (должно быть «нет»)?

## Карта: где ИИ есть и где сознательно нет

| Место | ИИ? | Что используем | Почему | Приоритет |
|---|---|---|---|---|
| Свободный текст в мастере | **Да** | Небольшая модель выбора из вариантов + парсер суммы ([40-02](02-free-text-wizard-spec.md)); ответы только подсказками с подтверждением (D-094). Какая модель — по итогам T-001 | Клиент пишет как думает. Конкретная польза, запасной путь — кнопки | Should (D-065) |
| Парсер выписки 1С | Нет | Обычный разбор файла по формату | Формат известен, ИИ не нужен (D-065) | Must/Should |
| PDF отчётности, сканы | Возможно позже | Текст из PDF + поиск строк; OCR; всегда с подтверждением человеком | Сейчас PDF только для просмотра андеррайтером; извлечение цифр — Could (D-095, [40-03](03-document-ingestion-options.md)) | Could |
| Скоринг риска | **Нет** | Скоркарта (D-074) | Объяснимо для регулятора; бустинг на синтетике ничего не добавит | Must |
| Антифрод, аномалии | **Нет** | Правила сверки (D-076) | Только флаги по понятным правилам; ML-поиск на синтетических данных нечестен | Must |
| Сверка ФИО и названий | Нет | Нормализация и нечёткое сравнение (`rapidfuzz`) | Алгоритм, не модель | Should |
| Запрещённая цель в тексте | Нет | Правила и ключевые слова | Цель выбирается из списка | Could |
| Выбор продукта | **Нет** | Таблица правил (D-011) | Объяснимо, тестируется один в один | Must |
| Объяснение отказа клиенту | **Нет** (пока) | Шаблоны по кодам причин | LLM-перефразирование — Q-007, **отложено пользователем** | Must (шаблоны) |
| Записка андеррайтеру | **Нет** (пока) | Шаблонная сводка | То же, Q-007 | Should |
| Чат-помощник | Нет | FAQ-подсказки | Нужна LLM, Q-007 | Could, после всего |
| Лента новостей | Нет | — | Не относится к кейсу (D-019) | Won't |

## Что считаем «ИИ», а что нет

- ИИ — любая обученная модель, чьи ответы мы не можем свести к понятному правилу.
- Не ИИ: парсер суммы по правилам, `rapidfuzz`, `pymorphy3`, скоркарта (таблица интервалов, баллы), расчёт DSCR. Скоркарту потом можно пересчитать регрессией (D-074), но на выходе остаётся таблица, которую можно прочитать глазами.

## Ресурсы

| Профиль | Память по лимитам | Комментарий |
|---|---|---|
| Основной без `ai` (если отключить) | ≈ 2,3 ГБ | Всё работает, мастер на кнопках |
| **Запуск по умолчанию: основной + `ai`** | ≈ 3,4 ГБ (ожидаемо ≈ 2,3 ГБ) | `nlu` до 1 ГБ ([50-01](../50-architecture/01-overview.md)); цель ≤ 4 ГБ выполняется |
| Генеративная LLM (Q-007) | + 2–5 ГБ | Профиль `llm`, на свой риск, не планируется |

## Решённые развилки

**Q-136. Включён ли профиль `ai` по умолчанию.** Решено 21.10 (D-094): включён везде, и локально, и на облачном стенде (вариант Б, шире рекомендации агента). Запуск `docker compose up` поднимает `nlu` без дополнительных флагов; бюджет памяти пересчитан в 50-01. Если модель не загрузилась, мастер продолжает работать на кнопках.

## Заметки для реализации

- Настройки: `NLU_ENABLED` (по умолчанию `true`), `NLU_BASE_URL` ([50-13](../50-architecture/13-config-and-profiles.md)); профиль compose `ai`.
- Тест «ядро не зависит от ИИ»: в `decisioning` нет импорта клиента `nlu` (import-linter, [50-04](../50-architecture/04-modules-and-boundaries.md)).
- e2e: весь мастер проходится без `nlu`; с недоступным `nlu` поле «своими словами» скрыто, ошибок нет.
- В README раздел «ИИ в проекте»: что делает, чего не делает, сколько ест, как отключить.
