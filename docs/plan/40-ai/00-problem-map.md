# Карта задач: где ИИ и NLP дают понятную ценность

| | |
|---|---|
| Статус | REVIEW |
| Владелец | Агент A |
| Зависит от | D-011, D-032, D-058 в [реестре](../00-meta/05-decisions-index.md) |
| Обновлено | 21.10.2026, ред. 2: сведение R-002 (D-019, D-094, D-095) |

Кейс: «ИИ — только там, где он создаёт понятную ценность», LLM только с открытыми весами, у жюри обычный ПК без GPU. Поэтому:

- **ИИ не принимает кредитных решений** (D-032);
- **у каждой функции есть путь без ИИ**: правила или шаблоны. Без ИИ всё работает, с ИИ работает удобнее;
- модели **вшиваются в образ при сборке** (веса с Hugging Face, докачка и проверка хеша; в публичном образе GHCR модель уже внутри, D-094): загрузчик Hugging Face на этой машине зависал;
- всё работает **на CPU**: маленькие модели, ONNX там, где возможно.

## Генеративная LLM: отдельный вопрос (Q-007)

Задачи 5, 6 и 9 выигрывают от LLM (например, Qwen 3–4B через llama.cpp или Ollama на CPU, 2–5 ГБ). Задачам 1–4, 7, 8 она не нужна. Решение «брать LLM или нет» (Q-007 отложен пользователем, генеративную LLM не включаем) не блокирует остальное: подключение через OpenAI-совместимый адрес `LLM_BASE_URL` и отдельный профиль compose.

## Как выбираем модели

Для каждой задачи с моделью делается замер на нашем наборе данных (`40-07`). Например, для задачи 1 это 50+ русских фраз с правильными ответами. Порог: **≥ 80% точности и < 1–2 с на CPU**. Таблица результатов идёт в документацию: жюри увидит, что модели выбраны по данным.
