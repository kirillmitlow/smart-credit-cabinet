## Цель

Главный артефакт для жюри (D-064): первая страница, которую открывают. Здесь разделы, не зависящие от кода: назначение, архитектура, требования, ограничения, развитие.

## Входит / не входит

- **Входит:**
  - Разделы по плану [80-06](../06-readme-plan.md): что это, быстрый старт (3 команды), требования к окружению (Docker, RAM, диск, порты, Windows), архитектура (картинка и 5 абзацев), компоненты, что смоделировано и ограничения/допущения (раздел 12 спецификации моков + «не моделируем»), развитие, лицензии, версия и тег
  - Таблица «Требование кейса → где посмотреть» (компактная версия [80-05](../05-submission-checklist.md))
  - Таблица «Устранение неполадок» (занят порт, мало памяти, долгая сборка, не `healthy`, как сбросить)
  - Язык простой, без жаргона, термины с пояснением; верх README читается за минуту
- **Не входит:**
  - Генерируемые части ([T-531](T-531-readme-generated.md)) и сценарий самопроверки ([T-532](T-532-jury-self-check-readme.md))
