## Цель

Подделку журнала видно: каждое событие заявки хранит хеш предыдущего события той же заявки, у администратора есть проверка целостности (Q-066 Б, после сквозного сценария).

## Входит / не входит

- **Входит:** столбцы `prev_hash`, `hash` в `application_events`, расчёт в одной функции записи; ручка/кнопка администратора «проверить целостность».
- **Не входит:** глобальная цепочка (только по заявке, чтобы записи не вставали в очередь).
