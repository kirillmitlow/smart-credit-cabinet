## Цель

Каждый экран получает тесты «как пользователь» с данными по схеме, проверкой доступности и управляемым потоком событий (Q-050 А).

## Входит / не входит

- **Входит:** Vitest + Testing Library + user-event, MSW с обработчиками из orval, фабрики данных, `vitest-axe` во всех экранных тестах; управляемый мок `EventSource` для таймлайна; порог покрытия 70% по строкам для `features/`, `components/`, `lib/` без `api/generated` (блокирует слияние); правила: без snapshot-тестов вёрстки; ищем по роли и подписи.
- **Не входит:** сами экранные тесты (в задачах экранов); Playwright ([T-518](T-518-playwright-harness.md)).
