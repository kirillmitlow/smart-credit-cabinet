## Цель

Мок АБС отвечает, клиент ли компания нашего банка, отдаёт месячные обороты по расчётному счёту и кредиты, выданные банком. По оборотам считается выручка (D-036).

## Входит / не входит

- **Входит:**
  - `GET /api/v1/customers/{inn}` (`404` — не клиент), `GET /customers/{inn}/turnover?months=1..24`, `GET /customers/{inn}/loans`, `GET /accounts/{n}`, `GET /loans/{id}`
  - База `mock_bank_core` (клиенты, счета, обороты по месяцам, кредиты, проводки, комплаенс-списки) и миграции; `AdminHandler` с телом `customer`, `accounts[]`, `turnover[]`, `loans[]`, `compliance`
  - Номера счетов с верным ключом (модуль [T-101](T-101-mocks-common-ids.md)), ссудный счёт создаётся автоматически для записанного кредита
  - Только месячные агрегаты (`incomingRub`, `incomingNetRub`, `outgoingRub`, `counterpartiesIn`, `counterpartiesOut`), отдельных операций и личных счетов нет
- **Не входит:**
  - Выдача и открытие счёта ([T-116](T-116-mocks-bank-core-disbursement.md), [T-117](T-117-mocks-bank-core-open-account.md))
  - Комплаенс ([T-118](T-118-mocks-bank-core-compliance.md))

## Критерии приёмки

- [ ] Примеры 7.1, 7.2 и 7.5 воспроизводятся; для не-клиента `404`
- [ ] `months` вне 1–24 даёт `422`; месяцев в ответе не больше, чем компания обслуживается
- [ ] Запись кредита с УИд даёт тот же `contractUid` для чтения; ссудный счёт создан и проходит проверку ключа
- [ ] Блокировка счёта (`BLOCKED`) отражается в `GET /customers/{inn}`
- [ ] OpenAPI описывает все пять эндпоинтов
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)

## Тесты

Тесты роли на записанных вручную данных: клиент с оборотами, не клиент, клиент с кредитом, блокированный счёт.

## Заметки для реализации

- Выручка в ядре считается из оборотов: форма `incomingNetRub` важна ([10-02](../../10-product/02-personas.md), Соколова: «поступления − списания»).
- Ключ роли `BANK_CORE_API_KEY`, порт хоста 8104.
