## Цель

D-066: весь compose ≤ 4 ГБ. Плановые цифры 50-01 заменяются измеренными, чтобы README не врал.

## Входит / не входит

- **Входит:**
  - Скрипт `scripts/measure.sh`: `docker stats --no-stream` после прохода персон, сумма по контейнерам, время первой сборки и время до `healthy` на чистой машине
  - Сводка для README: основной профиль, основной + `ai`, основной + `obs` (память и диск)
  - Если ограничение 4 ГБ нарушено, задача оформляет правку лимитов или список того, что режем
  - Результат сохраняется в `docs/` как снимок с датой и описанием железа
- **Не входит:**
  - Оптимизация, если цифры плохие (отдельная задача)
