## Цель

Проверка «сколько можно дать»: DSCR ≥ 1,25, стресс-DSCR ≥ 1,0 при шоке выручки, весь долг ≤ годовой выручки, особые лимиты продукта и обратная задача — максимальная сумма и минимальный срок, проверенные прямым расчётом.

## Входит / не входит

- **Входит:** `DSCR = CF / (E + P_new)` с платежом из графика; стресс `CF·(1 − s)` при шоке из [T-287](T-287-features-trend-volatility.md); потолок долга; серые зоны выдаёт маршрут ([T-296](T-296-routing-authority.md)); ограничения продуктов: линия — проценты на весь лимит и лимит ≤ 0,5 месячной выручки; овердрафт ≤ 30% средних чистых поступлений; контракт ≤ 80% неоплаченной части, срок до даты оплаты + 1 мес.; инвестиционный ≤ 70% оценки залога; обратная задача: `P_max = CF/1,25 − E`, `S_max` по сроку (аннуитет, bullet, линия), округление вниз до шага 50 000 с проверкой прямым расчётом; `n_min` по формуле с проверкой; место под вероятностный стресс: порог `P_def12` из политики подключается отдельной задачей ([T-315](T-315-stress-pipeline-integration.md)); до этого поле `null`; все нарушения собираются списком, не останавливаясь на первом (шаги 8–10 независимы).
- **Не входит:** встречные ([T-297](T-297-counter-offers-optimizer.md)); вероятностный стресс ([T-314](T-314-stress-test-probabilistic.md)).
