## Цель

Вторая половина коллекции запросов (RQ-19): сценарий самопроверки жюри по персонам на уровне `api`. Запросы идут по реальному пути: вход, заявка, решение.

## Входит / не входит

- **Входит:**
  - `docs/api/collection/api/`: по папке на каждую из 9 персон (сброс → вход → заявка → ожидание → проверки), проверки ключевых полей и статусов
  - Дополнительные папки: «Демо» (`/demo/personas`, `/demo/reset`, `/demo/chaos/{system}`, `/demo/scenarios`), «Банк» (очередь, карточка, решение)
  - Окружения `local` и `ci`, переменные (ИНН, куки сессии) без реальных секретов
  - Запуск `bru run` проходит против чистого стенда; подключение к CI ([T-512](T-512-ci-e2e.md))
- **Не входит:**
  - Коллекция для моков ([T-140](T-140-mocks-bruno-collection.md))

## Критерии приёмки

- [ ] Для каждой из 9 персон есть папка, воспроизводящая ожидаемый исход
- [ ] `bru run` по всей коллекции зелёный на свежем стенде
- [ ] Красный запрос приводит к красному CI
- [ ] Коллекция открывается в Bruno без правки путей
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)

## Тесты

`bru run --env ci` в задании `e2e`.
