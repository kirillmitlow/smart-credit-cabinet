## Цель

Из имитатора получается портфель на 20–40 тысяч заявок с историей дефолтов, на котором считаются метрики скоркарты и идут массовые тесты (D-075); доля дефолтов — около 6% в год (коридор 4–10%, данные ЦБ).

## Входит / не входит

- **Входит:** режим портфеля: seed, число заявок, версия правил → признаки «как из моков», запрос, исход «дефолт за 12 мес. / за срок»; потоком, без хранения траекторий; решение по каждой заявке принимает то же `decide()` из [T-300](T-300-decide-assembly.md); калибровка бисекцией по `λ` на одном seed (N=60 000, 10 шагов, остановка при |доля − 6%| < 0,1 п.п.), затем `s_m`; проверки после калибровки: монотонность (корзины DSCR 16,4 → 8,8 → 4,3 → 1,8%), отрасли в коридоре, ручки работают в ожидаемую сторону.
- **Не входит:** метрики и отчёт ([T-317](T-317-validation-metrics.md), [T-318](T-318-validation-report-build.md)); массовые тесты ([T-320](T-320-synthetic-population-tests.md)).

## Критерии приёмки

- [ ] Доля дефолтов портфеля из 20 000 в [4%; 10%], каждая отрасль в [2%; 15%] (тест)
- [ ] Бюджет: 40 000 заявок × 60 мес. < 60 с на чистом Python (оценка ~7 с на генерацию)
- [ ] Монотонность: рост платежа, постоянных расходов, волатильности не уменьшают долю дефолтов (допуск 0,5 п.п.)
- [ ] Паспорт запуска: версия правил, версия имитатора, seed, число заявок, хеш конфига
- [ ] Тесты написаны и зелёные (`make check`)
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
