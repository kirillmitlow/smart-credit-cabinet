## Цель

Три персоны с «негативными» исходами: ликвидация, самозанятый и отказ по налоговому долгу с просрочкой в БКИ.

## Входит / не входит

- **Входит:**
  - `vektor` (ИНН `0018889990`): статус `LIQUIDATING`, недостоверный адрес, УСН 6%, налоговых долгов нет, БКИ чистый (1 закрытый кредит, чтобы не было второго стопа); заявка `EXPRESS` 2 млн / 12 мес; `REJECTED`, `COMPANY_NOT_ACTIVE`
  - `orlov` (ИНН `001211122200`): нет в реестре, НПД `status: true`; БКИ и bank-core `SKIPPED`; `NOT_ELIGIBLE`, `expectedReasonCodes: [SELF_EMPLOYED]`
  - `romashka` (ИНН `0015557771`): 7 лет, 46.73, УСН 15%, налоговый долг 1,15 млн, отчётность 2025 (форма упрощённая, 2110 = 95 млн, проценты 0,6 млн, долгосрочные обязательства 0,5 млн), два активных кредита (пример 6.1), просрочка 94 дня на 452 тыс., 6 чужих запросов, 2 отказа; `WORKING_CAPITAL` 3 млн / 6 мес; `REJECTED`, `expectedReasonCodes: [TAX_ARREARS_HIGH, CURRENT_OVERDUE_90]` (главный код первый)
  - Блоки `users` у `vektor` и `romashka`; у `orlov` пользователя нет (вход даёт объяснение)
- **Не входит:**
  - Остальные персоны ([T-133](T-133-mocks-personas-large.md), [T-134](T-134-mocks-personas-garipov-quickstart.md))

## Критерии приёмки

- [ ] Отчёт БКИ по Ромашке совпадает с примером 6.1 (просрочка 94 дня, сводка, корзины)
- [ ] У Ромашки налоговый долг > 10% месячной выручки (≈ 7,9 млн/мес)
- [ ] `orlov`: регистр отдаёт `404`, НПД `true`; `vektor`: регистр отдаёт статус ликвидации
- [ ] Проценты (2330) и долг (1400) в отчётности Ромашки согласованы с долгом в БКИ (правило из 10.3)
- [ ] Все три сценария применяются без `422` и описаны в `GET /scenarios`
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)
