## Цель

Сервис блокировок счетов ФНС даёт ещё один стоп-сигнал почти бесплатно (Q-021). Мок отдаёт решения о приостановке операций по счетам, в том числе по нашему БИК.

## Входит / не входит

- **Входит:**
  - `GET /api/v1/account-blocks/{inn}?bik=040000999`: список решений (`decisions[]`), без блокировок — `200` с пустым списком; `source: FNS_BLOCKS`
  - Поле `accountBlocks[]` в админ-теле `PUT` (номер, дата, код налоговой, БИК, причина, дата снятия)
  - Фильтр `bik`: решения с чужим БИК не влияют на ответ по нашему
- **Не входит:**
  - Статус счёта `BLOCKED` в bank-core (его согласует валидатор [T-126](T-126-mocks-consistency-rules.md), мок АБС сам решение не читает)
