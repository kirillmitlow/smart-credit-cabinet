## Цель

Клиент видит кредиты, ближайший платёж и график, который совпадает с графиком предложения; платежи и просрочки не моделируются (надпись про это).

## Входит / не входит

- **Входит:** список (продукт, сумма или лимит, остаток, ближайший платёж), карточка (условия, график, «Скачать договор»); виды: аннуитет, под контракт (проценты и долг в конце), линия/овердрафт — лимит и ставка без графика; пусто: «Кредитов пока нет».
- **Не входит:** —.

- [x] Платёж на карточке = платёж в графике (TS-001, TS-090)

Vitest + MSW + axe.

## Заметки для реализации

- Договор: в `LoanDetail` нет id договора, поэтому «Скачать договор» берёт `contractId` из `GET /applications/{applicationId}/offer`, как экран подписания. Нет договора в ответе, нет и ссылки.
- Колонка «Остаток долга» в графике считается на экране: выданная сумма минус нарастающий итог основного долга. API её не отдаёт.
- Линия и овердрафт определяются по `repaymentType = REVOLVING` или `kind` `CREDIT_LINE`/`OVERDRAFT`: показываем лимит (`limitRub`) и ставку, без остатка, платежа и графика.
- Список просит 100 кредитов одним запросом; на главной три последних. Постраничной подгрузки нет (`nextCursor` только даёт подпись «Показаны последние N»).
