## Цель

Все тексты интерфейса лежат в одном месте и единым тоном; суммы, даты и проценты форматируются одной функцией (`1 500 000 ₽`, `21,5%`, `28 октября`).

## Входит / не входит

- **Входит:** каталог `texts/` с типизированными ключами: статусы и шаги таймлайна, ошибки по `code`, пустые состояния, подсказки к терминам, демо-пометки (наполнение — [T-437](T-437-web-texts-full-60-06.md)); форматтеры: деньги с неразрывными пробелами, проценты с запятой, даты `21 окт 2026`, срок «12 месяцев»; тест запрещённых слов в клиентских текстах: «аннуитетный», «обеспечение», «кассовый разрыв», «цель кредитования», «грейд», «скоринг», «DSCR», «стоп-фактор».
- **Не входит:** полный словарь 60-06 ([T-437](T-437-web-texts-full-60-06.md)).

## Критерии приёмки

- [x] Форматтеры проходят таблицу примеров (границы, ноль, отрицательное, огромные суммы)
- [x] Текст ошибки берётся по `code`, неизвестный код → общий текст и номер запроса
- [x] Строк пользовательского текста вне `texts/` в экранах нет (правило ревью + тест на литералы в компонентах заданных папок)
