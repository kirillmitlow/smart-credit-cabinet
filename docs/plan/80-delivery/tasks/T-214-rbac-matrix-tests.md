## Цель

Автоматически доказать, что права соответствуют таблице [10-03](../../10-product/03-users-and-roles.md): каждая ручка закрыта, чужая компания даёт `404`, а роли ведут себя по матрице.

## Входит / не входит

- **Входит:** тест, обходящий все маршруты из OpenAPI без сессии и ожидающий `401` (кроме публичных); параметризованная матрица «ручка × роль» из [10-03](../../10-product/03-users-and-roles.md), пара «своя/чужая компания» для каждого ресурса с `companyId`; правило «эндпоинт без `require`/фильтра компании не проходит тест».
- **Не входит:** сами ручки (по задачам модулей).

## Критерии приёмки

- [ ] Тест падает, если появилась ручка без зависимости прав
- [ ] Бухгалтер получает `ROLE_CANNOT_SIGN` на подписи договора, но может подписать согласия компании при действующем полномочии (D-091)
- [ ] Поручитель видит только адресованные ему действия и сводку «за что поручаетесь» (D-096)
- [ ] Тесты написаны и зелёные (`make check`)
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
