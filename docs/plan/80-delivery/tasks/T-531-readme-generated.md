## Цель

Таблицы, которые устаревают быстрее всего, не пишутся руками: список переменных окружения, порты, ИНН и ожидаемые исходы персон, показатели качества.

## Входит / не входит

- **Входит:**
  - Скрипт `scripts/build_readme_parts.py`: вставляет в README между маркерами таблицу переменных (из `Settings`/`.env.example`), таблицу портов и компонентов (из compose), таблицу персон (ИНН, что просит, ожидаемый исход — из `GET /scenarios` живого стенда или снимка), таблицу «Качество» ([T-521](T-521-synthetic-report-ci.md))
  - Команда `make readme`; проверка в CI: README не отстаёт от источников (diff после генерации пуст)
  - Снимок персон сохраняется в репозитории, чтобы README собирался без поднятого стенда
  - ИНН синтетические (регион `00`) — пометка в таблице
- **Не входит:**
  - Ручные разделы README ([T-530](T-530-readme-static.md))

## Критерии приёмки

- [ ] Изменение значения по умолчанию в `.env.example` без перегенерации README делает проверку красной
- [ ] Таблица персон содержит ИНН, запрос и ожидаемый исход всех 9 персон и ссылку на 10 технических
- [ ] Таблица «Качество» подтягивает числа из артефактов CI или помечена датой снимка
- [ ] Генерация воспроизводима без сети
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)
