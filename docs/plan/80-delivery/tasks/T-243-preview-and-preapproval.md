## Цель

Мастер и главная показывают ориентир «до N ₽, ставка от X%, платёж Y» тем же ядром без БКИ, не обещая больше, чем даст полный расчёт (D-018).

## Входит / не входит

- **Входит:** `preview()` поверх `decide(mode=PREVIEW)`: осторожные значения БКИ-факторов (30-07), обороты из АБС для клиентов банка; `GET /companies/{id}/preapproved-offer` (только клиенты банка); инвариант согласованности режимов.
- **Не входит:** решение по отправленной заявке ([T-275](T-275-decision-persistence.md)).
