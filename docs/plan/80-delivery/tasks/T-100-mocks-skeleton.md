## Цель

Появляется один Python-проект `mocks/` и один Docker-образ, из которого запускаются все пять контейнеров. Роль выбирается переменной `MOCK_ROLE`. К концу задачи в compose живут пять «пустых» сервисов с `/health/*` и Swagger, а остальные задачи моков дописывают роли по одной.

## Входит / не входит

- **Входит:**
  - `mocks/pyproject.toml` и `uv.lock` (Python 3.13, FastAPI, uvicorn, Pydantic v2, pydantic-settings, SQLAlchemy 2, Alembic, httpx, pytest); отдельный проект, код `api` не импортируется
  - `Dockerfile`: многоступенчатая сборка, `uv sync --frozen`, базовый образ по точному тегу, запуск `uvicorn --workers 1`
  - `app/main.py` с `create_app()`: подключает роутеры по `MOCK_ROLE` (`registry`, `tax`, `bki`, `bank_core`, `scenarios`); пустые пакеты `roles/<роль>/` по схеме из раздела 3.3
  - `app/settings.py`: `MOCK_ROLE`, `MOCK_LATENCY_MS` (диапазон `200-600`), `MOCK_API_KEYS`, `MOCK_ADMIN_KEY`, `DATABASE_URL`, `APP_TODAY`, `BANK_BIK`
  - `app/health.py`: `GET /health/live` и `GET /health/ready` (пока `ready` = процесс поднялся; проверку БД добавит [T-103](T-103-mocks-common-clock-db.md))
  - `.dockerignore`: в образ не попадают `docs/`, тесты, `.git`
- **Не входит:**
  - Бизнес-эндпоинты, модели БД, middleware (задачи [T-101](T-101-mocks-common-ids.md)…[T-104](T-104-mocks-common-idempotency.md) и ролевые)
  - Написание compose-файла (это [T-502](T-502-compose-main.md))

## Критерии приёмки

- [ ] `docker build ./mocks` проходит; один и тот же образ стартует с каждой из пяти ролей и отвечает `200` на `/health/live`
- [ ] Пустая или неизвестная `MOCK_ROLE` останавливает процесс с понятным сообщением на русском
- [ ] `/docs` и `/openapi.json` открываются без ключа у каждой роли; заголовок страницы показывает имя роли
- [ ] Структура каталогов совпадает с разделом 3.3 спецификации (лишних пакетов нет)
- [ ] Размер образа записан в описание PR; в образе нет `docs/` и PDF кейса
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)

## Тесты

pytest + `httpx.AsyncClient`: по одному smoke-тесту на каждую из пяти ролей (приложение собирается, `live` отвечает, неверная роль даёт ошибку конфигурации).

## Заметки для реализации

- Один процесс на контейнер обязателен: режим chaos хранится в памяти процесса ([моки](../../../specs/mocks.md), 3.1).
- В ТЗ моков строка подключения с `postgresql+asyncpg://`; драйвер `api` другой (psycopg 3, D-080). Драйверы не смешиваем: у `mocks/` свой lock-файл.
- Лимит памяти контейнера 160 МБ ([50-01](../../50-architecture/01-overview.md)) — не тащить в зависимости pandas, numpy и прочее тяжёлое.
