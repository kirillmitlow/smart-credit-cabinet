# T-292. Рассчитать ставку по ожидаемым потерям

| | |
|---|---|
| Статус | DONE |
| Владелец | не назначен (Claude Code или Codex, по очереди смен) |
| Ветка | `feat/pricing-rate` |
| Оценка | ~3 ч |
| Приоритет | M (Must) |
| Тонкий сквозной сценарий | да |
| Зависит от | [T-291](T-291-scoring-scorecard-grades.md) |

## Цель

Ставка складывается из понятных частей: стоимость денег, ожидаемые потери (PD × LGD), расходы, плата за капитал; результат округляется и зажимается в коридор продукта (D-071).

## Входит / не входит

- **Входит:** раздел `pricing`: ключевая ставка + 1 п.п. (15%), LGD 45% без залога / 35% с залогом, расходы 2% (экспресс +2 п.п.), плата за капитал 2%, округление до 0,5 п.п., коридор продукта; разбивка ставки для карточки андеррайтера и клиента («из чего складывается»); подсказка «с залогом ставка была бы…»; ставка считается до лимитов и не зависит от суммы (D-084).
- **Не входит:** пересчёт после заседания ЦБ (новая версия политики, [T-274](T-274-policy-loader-versions.md)).

## Критерии приёмки

- [ ] Ставки по [30-17](../../30-decisioning/17-persona-walkthrough.md): экспресс A 21,5% / B 22,5% / C 24,0%, остальные продукты A 19,5% / B 20,5% / C 22,0%; с залогом A 21,5% / 19,5%, C 23,5% / 21,5%; точные сырые значения (19,45 → 19,5; 22,35 → 22,5; 24,15 → 24,0) — округление до ближайших 0,5 п.п.
- [ ] INV-05, INV-06: залог не повышает ставку, хуже грейд — ставка не ниже, всегда в коридоре продукта
- [ ] Поручительство LGD не меняет (ставка `quick-start` 24,0%); ставка не зависит от суммы (D-084)
- [ ] Тесты написаны и зелёные (`make check`)
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале

табличные unit + property INV-05/06.
