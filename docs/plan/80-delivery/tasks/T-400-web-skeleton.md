## Цель

Пустое, но собираемое приложение: тема Mantine с красным акцентом, нейтральное название продукта, структура `features/` по [50-03](../../50-architecture/03-repo-and-conventions.md), строгий TypeScript. Дальше экраны ложатся на готовые рельсы.

## Входит / не входит

- **Входит:** Vite + React 19 + TypeScript `strict`, pnpm (версия в `package.json`), Node LTS в `.nvmrc`, Mantine (версию фиксирует lock после пробной сборки), шрифты и иконки локально (без CDN); тема: красный акцент, нейтральное название («Кредитный кабинет», без логотипа и имени банка), светлая тема, минимальная ширина 1280 px и подсказка «Откройте на компьютере» ниже; структура `src/app`, `features/<имя>` (auth, home, catalog, wizard, application, offers, loans, backoffice, notifications, demo), `components/`, `api/generated/` (не править руками), `lib/`, `texts/`; ESLint (flat config, `jsx-a11y` — ошибки), Prettier, `tsc --noEmit`; запрет `any` без комментария-причины.
- **Не входит:** Dockerfile и nginx ([T-401](T-401-web-dockerfile-nginx.md)); роутинг ([T-403](T-403-web-routing-zones-guards.md)); общие линтеры и pre-commit ([T-501](T-501-linters-precommit.md)).

## Критерии приёмки

- [ ] `pnpm build` и `pnpm lint` проходят на пустом каркасе; сборка по `--frozen-lockfile`
- [ ] Тема применяется к тестовой странице: красный акцент, достаточный контраст кнопок (axe без нарушений)
- [ ] В бандле нет запросов к внешним CDN и шрифтам (проверка сетевых запросов)
- [ ] Выбор макета не зашит в код: цвета и радиусы — через токены темы, так что смена направления после этапа 2 макетов не требует переписывать экраны
- [ ] Тесты написаны и зелёные (`make check`)
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале

## Тесты

unit/smoke: рендер корневого компонента, a11y-проверка; проверка отсутствия внешних запросов.
