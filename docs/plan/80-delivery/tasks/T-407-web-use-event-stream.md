## Цель

Статусы идут без перезагрузки: один поток на вкладку сбрасывает кэш нужных запросов, а экран перечитывается обычным запросом. Три состояния связи видны пользователю.

## Входит / не входит

- **Входит:** один `EventSource` на вкладку с параметром зоны, `Last-Event-ID` по умолчанию из браузера, `retry` 3 с; карта событий → инвалидация кэша: `status_changed`, `step_done` (заявка, таймлайн, список, главная), `task_created` (задачи, уведомления, главная), `resync` (всё), `auth_expired` (на `/login` с сообщением); состояния «подключено / переподключение / опрос раз в 5 с» после 3 неудач; возврат на поток, когда он оживает; очистка при выходе.
- **Не входит:** отображение индикатора ([T-404](T-404-web-shell-demo-badge.md)).
