## Цель

Одна команда выгружает OpenAPI `api` и пяти моков в `docs/api/` и перегенерирует клиент фронта (orval). Закрывает RQ-18 и ловит расхождения контрактов.

## Входит / не входит

- **Входит:**
  - `make openapi`: `api` (`docs/api/api.openapi.yaml`) + пять файлов моков ([T-139](T-139-mocks-openapi-export.md)) + клиент `web/src/api/generated` (orval, руками не правим)
  - Выгрузка детерминирована и не зависит от БД и времени
  - Проверка `git diff --exit-code` после выгрузки в CI ([T-511](T-511-ci-contracts-security-notices.md))
  - Короткая страница `docs/api/README.md`: что лежит, как получить Swagger, как запускать коллекции
- **Не входит:**
  - Сами правки схем (задачи `api`)
  - Spectral и oasdiff ([T-511](T-511-ci-contracts-security-notices.md))

## Критерии приёмки

- [ ] Команда создаёт или обновляет все шесть файлов и клиент без ручных шагов
- [ ] Повторный запуск не меняет файлы (детерминизм)
- [ ] Изменение ручки без запуска команды ломает CI
- [ ] `docs/api/README.md` объясняет назначение каждого файла простыми словами
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)
