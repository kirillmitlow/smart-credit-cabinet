## Цель

Команда проводит 3–5 юзабилити-тестов (D-009). Сценарий и форма есть в 10-04, задача агента — подготовить стенд, лист записи и инструкцию ведущему, чтобы тесты можно было провести на выходных 24–25.10.

## Входит / не входит

- **Входит:**
  - Файл `docs/research/usability-01.md` (шаблон формы записи из 10-04) и короткая инструкция ведущему (как поднять стенд, сбросить данные, не подсказывать)
  - Список персон и задач T1–T8, рекомендованное деление между участниками (T7, T8 — двоим)
  - Решение «тестируем со свободным текстом или без» и порядок (по двум вариантам у разных участников)
  - Порядок переноса находок: серьёзность 2–3 становятся задачами по экранам, итог дописывается в 10-04
- **Не входит:**
  - Сами тесты (люди) и исправление находок

## Входные документы

- [10-04](../../10-product/04-research-jtbd.md) (сценарий юзабилити-теста, форма записи)
- [Реестр решений](../../00-meta/05-decisions-index.md): D-009, D-064

## Критерии приёмки

- [ ] Ведущий может провести тест, не читая остальных документов плана
- [ ] Форма записи совпадает с 10-04
- [ ] Указано, что делать, если провели меньше трёх тестов (так и писать)
- [ ] Файл с результатами лежит в `docs/research/`
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)
