## Цель

После `SIGNED` заявка идёт в `DISBURSING` и завершается `DISBURSED`: не-клиенту автоматически открывается счёт по заявлению из пакета (один код), затем выдача, запись кредита и графика, сообщение в БКИ.

## Входит / не входит

- **Входит:** переход `SIGNED → DISBURSING` и шаги outbox в одной транзакции (`disbursements` с уникальным `application_id`); шаги из [20-05](../../20-process/05-disbursement-and-after.md): проверка → открытие счёта → выдача (`disb:{заявка}`) → `loans` и `payment_schedule` → `OBLIGATION_OPENED` → `DISBURSED`; линия и овердрафт после выдачи — только лимит (D-093); график считает `api`, не АБС; завершает `DISBURSED` обработчик подтверждения, а не HTTP-ответ клиенту; клиент видит шаги «Открываем счёт», «Зачисляем», номер счёта.
- **Не входит:** тесты «ровно один раз» ([T-343](T-343-disbursement-exactly-once.md)); экраны ([T-426](T-426-web-accept-and-sign.md)).
