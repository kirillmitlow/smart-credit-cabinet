## Цель

Один вопрос на экран крупными карточками: на что деньги → уточнение → сумма → комфортный платёж → залог (только если нужно). Ответы переходят в черновик заявки, возвращаться и менять можно.

## Входит / не входит

- **Входит:** слоты и ветвление по [10-07](../../10-product/07-need-wizard.md); «Не знаю» с подсказкой («сколько обычно закупаете в месяц?»); прогресс «Шаг 2 из 5»; «Назад» с пересчётом; сумма — поле числа с понятными ошибками; комфортный платёж — 2–3 варианта «срок → платёж → переплата», тот, что по силам, помечен; создание заявки `DRAFT` и запись ответов в `draft`; фронт не копирует таблицу «ответ → продукт» — результат приходит с бэкенда.
- **Не входит:** результат подбора ([T-413](T-413-web-wizard-result-variant-card.md)); свободный текст ([T-414](T-414-web-wizard-free-text.md)).

## Что сделано и отступления (22.10.2026)

- Экран `/wizard` (`web/src/features/wizard/`): цель, уточнения по цели (регулярность, срок возврата, госзаказ), сумма, платёж (варианты «срок → платёж → переплата» из ответа бэкенда, по силам помечен), залог. Прогресс «Шаг N из M»: пока бэкенд не посчитал, платёж и залог считаются впереди, потом число уточняется.
- После суммы фронт делает предварительный `POST /wizard/recommendations` (без срока и залога): бэкенд сам говорит, нужны ли вопросы про платёж (`comfortableOptions`) и залог (`askCollateral`). Мастер создаёт и обновляет один черновик, `applicationId` запоминается.
- «Не знаю» везде. Исключение: у залога есть своя карточка «Не уверен». У суммы «Не знаю» показывает подсказку и позволяет идти без суммы.
- **Вопрос «Когда нужны деньги?» (`urgency`) не задаётся**: по 10-07 он не меняет продукт, бэкенд его не использует, а в карточке задачи его нет среди пяти шагов. Нужен будет, когда бэкенд начнёт сортировать рекомендации.
- Если срок не выбран («Не знаю» на платеже), он остаётся пустым; клиент заполнит его на шаге «Условия» заявки.
