## Цель

Один вопрос на экран крупными карточками: на что деньги → уточнение → сумма → комфортный платёж → залог (только если нужно). Ответы переходят в черновик заявки, возвращаться и менять можно.

## Входит / не входит

- **Входит:** слоты и ветвление по [10-07](../../10-product/07-need-wizard.md); «Не знаю» с подсказкой («сколько обычно закупаете в месяц?»); прогресс «Шаг 2 из 5»; «Назад» с пересчётом; сумма — поле числа с понятными ошибками; комфортный платёж — 2–3 варианта «срок → платёж → переплата», тот, что по силам, помечен; создание заявки `DRAFT` и запись ответов в `draft`; фронт не копирует таблицу «ответ → продукт» — результат приходит с бэкенда.
- **Не входит:** результат подбора ([T-413](T-413-web-wizard-result-variant-card.md)); свободный текст ([T-414](T-414-web-wizard-free-text.md)).
