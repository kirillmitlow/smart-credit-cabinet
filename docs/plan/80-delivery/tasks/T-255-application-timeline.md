## Цель

Таймлайн клиента строится из журнала `application_events`: шесть понятных шагов с подшагами проверки; внутренние поля клиенту не отдаются.

## Входит / не входит

- **Входит:** соответствие «статус/шаг конвейера → шаг клиента» из [20-02](../../20-process/02-application-states.md); подшаги «Проверяем данные»: реестр, налоговая, кредитная история и т. п. (по `step_code`); блок-пауза «Нужна ваша помощь» при `NEEDS_INFO`, понятные состояния «часть проверок затянулась» при `SOURCE_UNAVAILABLE`; андеррайтеру и админу — полный журнал отдельной моделью.
- **Не входит:** тексты шагов (ключи в [T-405](T-405-web-texts-dictionary-infra.md); сервер отдаёт `text_key` и параметры).
