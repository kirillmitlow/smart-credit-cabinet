## Цель

Свободный текст в мастере (D-060) работает, не ломая основной путь. По D-094 профиль `ai` включён везде, значит, `nlu` должен подниматься у жюри без дополнительных флагов.

## Входит / не входит

- **Входит:**
  - Сервис `nlu` (образ с вшитой моделью, без обращения к хабу моделей в рантайме, лимит ≈ 1 ГБ, healthcheck)
  - Решить и записать в PR, как «включён везде» выражается в compose: сервис без `profiles:` либо `COMPOSE_PROFILES=ai` в значениях по умолчанию; жюри не создаёт `.env`, поэтому одного `.env.example` недостаточно
  - Запасной путь: отключить `nlu` без правки файлов (например, `--scale nlu=0`); `api` при его отсутствии переключается на кнопки
  - Запись об итоговом бюджете памяти (основной ≈ 2,3 ГБ + `nlu` ≈ 1 ГБ по лимитам)
- **Не входит:**
  - Сборка и качество модели (задачи ИИ)
