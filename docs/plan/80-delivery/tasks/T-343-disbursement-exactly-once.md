## Цель

Деньги выдаются ровно один раз даже при `LOST_RESPONSE`, повторе outbox, падении воркера и двойном «Подписать».

## Входит / не входит

- **Входит:** сквозной сценарий `LOST_RESPONSE` в `mock-bank-core`: один кредит, один `Idempotent-Replayed`, один `OBLIGATION_OPENED`; ветка `409 ALREADY_DISBURSED` с другим ключом: читаем `customers/{inn}/loans` по `applicationRef`, сверяем сумму, иначе тревога; два параллельных «Подписать» не дают двух выдач (уникальность и условный переход); property на последовательностях сбоев.
- **Не входит:** общий chaos-набор ([T-394](T-394-resilience-chaos-tests.md)).
