## Цель

Входы `decide()` для трёх персон тонкого сценария, собранные вручную по данным моков, служат золотыми тестами ядра с первого дня.

## Входит / не входит

- **Входит:** снимки данных `sokolova` (ИП, чистый БКИ, клиент банка, обороты ≈ 900 тыс./мес.), `romashka` (налоговый долг 1,15 млн, просрочка 94 дня), `vektor` (LIQUIDATING); ожидаемые исходы, коды, баллы и числа из оракула [30-17](../../30-decisioning/17-persona-walkthrough.md) (допуски: рубли ±1, DSCR ±0,005, баллы, грейд, коды — точно); загрузчик фикстур для pipeline-тестов.
- **Не входит:** остальные персоны ([T-302](T-302-core-fixtures-all-personas.md)).
