## Цель

Конфигурация для облачного стенда: наружу только прокси, все секреты обязательны, админ-API моков недоступен снаружи ни при каких условиях.

## Входит / не входит

- **Входит:**
  - `docker-compose.cloud.yml`: `APP_ENV=cloud`, `restart: unless-stopped`, лимиты памяти, подстановки `${VAR:?}` для всех секретов (без значения по умолчанию у админ-ключа)
  - Порты моков и `api` не публикуются; наружу 80/443 через Caddy (вариант А из Q-072, только в этом файле)
  - Проксирование `/docs` и `/openapi.json` в `api` (Swagger моков только по служебным портам, которых нет)
  - Проверка: `docker compose -f docker-compose.yml -f docker-compose.cloud.yml config` падает без обязательных переменных
- **Не входит:**
  - Аренда и настройка VPS ([T-540](T-540-cloud-stand.md))

## Критерии приёмки

- [ ] Без любой из обязательных переменных compose отказывается стартовать с понятным сообщением
- [ ] На хост опубликованы только 80 и 443; порты `8000`, `8101–8105` недоступны
- [ ] SSE проходит через два прокси: буферизация отключена и в Caddy, и в nginx
- [ ] Админ-ключ по умолчанию отсутствует в облачном профиле
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)
