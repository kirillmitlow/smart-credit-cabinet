## Цель

Все переменные окружения описаны в одном файле, и скрипт гарантирует, что файл, `Settings` и значения по умолчанию в compose не расходятся.

## Входит / не входит

- **Входит:**
  - `.env.example` по группам таблиц 50-13: общие, хранилища, внешние системы, процесс и правила, ИИ, секреты; у каждой переменной комментарий «зачем» и пометка «только для разработки» у секретов, строка с `openssl rand -hex 24`
  - Скрипт `scripts/check_env.py`: каждая переменная из `Settings` (когда появится) есть в `.env.example` и наоборот; значения `${VAR:-…}` в compose совпадают с `.env.example`
  - Подключение скрипта к `make check` и CI-заданию `lint-py`
- **Не входит:**
  - Генерация таблицы переменных для README ([T-531](T-531-readme-generated.md))
  - Класс `Settings` (задача `api`)

## Критерии приёмки

- [ ] Файл содержит все переменные таблиц 50-13 и ни одного значения, похожего на настоящий ключ
- [ ] Скрипт падает, если переменная есть только в одном из мест (проверено добавлением тестовой переменной)
- [ ] Облачный профиль требует все секреты: у них нет значений по умолчанию в `.env.example` (только пример-подсказка)
- [ ] Скрипт запускается без Docker
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)
