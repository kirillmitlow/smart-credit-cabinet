## Цель

Андеррайтер видит, что ждёт решения: строка вспыхивает при появлении, видно «почему здесь» и рекомендацию ядра.

## Входит / не входит

- **Входит:** таблица: номер и время ожидания, компания, запрос, «почему здесь» (короткие названия кодов), рекомендация ядра цветной меткой, отметки «получен документ»/«клиент ответил»/«источник недоступен»; фильтры (статус «Ждут решения», продукт), сортировка «старые сверху», живое обновление по SSE `zone=bank`; состояния: пусто «Очередь пуста…», загрузка, ошибка с повтором, связь потеряна.
- **Не входит:** карточка ([T-430](T-430-web-bank-card.md)).

## Критерии приёмки

- [ ] Новая заявка появляется без обновления страницы
- [ ] Дольше 1 рабочего дня подсвечивается
- [ ] Вход по кнопке, клиентская сессия не пускает
- [ ] Тесты написаны и зелёные (`make check`)
- [ ] Документация и OpenAPI обновлены, если менялся контракт
