## Цель

Андеррайтер видит, что ждёт решения: строка вспыхивает при появлении, видно «почему здесь» и рекомендацию ядра.

## Входит / не входит

- **Входит:** таблица: номер и время ожидания, компания, запрос, «почему здесь» (короткие названия кодов), рекомендация ядра цветной меткой, отметки «получен документ»/«клиент ответил»/«источник недоступен»; фильтры (статус «Ждут решения», продукт), сортировка «старые сверху», живое обновление по SSE `zone=bank`; состояния: пусто «Очередь пуста…», загрузка, ошибка с повтором, связь потеряна.
- **Не входит:** карточка ([T-430](T-430-web-bank-card.md)).

## Реализация B, 23.10

Экран в features/bank/BankQueuePage.tsx: отдельный запрос с типами orval, пять колонок, server-side фильтры и курсор «Показать ещё», подсветка новых строк на2с, ожидание и overdue из ответа. Неизвестная рекомендация/статус обслуживания не подменяются одобрением или «не клиент». При пустом профиле обслуживания читается булево значение из последнего ENGINE-снимка, в том числе false; явное значение компании сохраняет приоритет. Документы не помечаются полученными, пока нет сервиса.

Общий useEventStream открывает только один поток bank; status_changed/step_done/task_created инвалидируют backoffice-кэш. Пока T-352 не готов и сервер отвечает404, включается предусмотренный резервный опрос5с с честным индикатором. TS-030 прошёл на живом конвейере: Соколова с инвестиционным запросом1млн/60мес и заявленным залогом, подпись согласий/отправка через UI → MANUAL_REVIEW → строка банка без перезагрузки. Это отдельный банковский сценарий, не замена оракулу Соколовой EXPRESS500тыс/12мес или полного V4 СтанкоПрома.

Банк выходит своей кнопкой: серверный bank-logout, отмена/удаление банковского кэша, клиентская сессия/кэш сохраняются. Ошибка выхода показывается с повтором.

Проверки: 41 целевая web-проверка (включая восемь экранных, мок EventSource, axe), полный make check с профилем ci, 412 web; 39 целевых API/архитектурных проверок. Два живых браузерных теста (независимые входы/выходы и очередь) прошли, включая фильтры и axe без critical/serious. Исправлен реальный слабый контраст зелёной метки; jsdom его не мог увидеть. Скриншот bank-queue.png сохраняется в output теста.
