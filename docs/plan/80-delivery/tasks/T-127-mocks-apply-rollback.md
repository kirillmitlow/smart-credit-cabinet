## Цель

`apply` раскладывает развёрнутые данные по мокам через их админ-API и откатывает всё при сбое одного. Половинчатых компаний не бывает.

## Входит / не входит

- **Входит:**
  - `split.py`: развёрнутые данные → четыре куска в терминах `PUT /admin/subjects/{inn}` каждого мока
  - `apply.py`: последовательная запись в registry, tax, bki, bank-core с заголовком `X-Scenario-Code`; журнал `scenario_applications` (система, действие, HTTP-статус, ошибка)
  - Откат: при сбое любого мока `DELETE /admin/scenarios/{code}` у уже записанных; сценарий получает `FAILED`, ответ `502 APPLY_FAILED` с названием системы
  - `POST /scenarios` создаёт и применяет (ответ `201` с `applied` по каждому моку: `OK`/`SKIPPED`/`FAILED`); `POST /scenarios/{code}/apply` стирает всё по компании, включая `RUNTIME`-записи, и создаёт заново
  - Статусы `PENDING`, `APPLIED`, `FAILED`
- **Не входит:**
  - Стартовое наполнение ([T-128](T-128-mocks-startup-fill.md)) и досинхронизация ([T-129](T-129-mocks-resync-reset.md))

## Критерии приёмки

- [ ] Пример ответа 10.2 воспроизводится: `applied` показывает `SKIPPED` для bank-core у не-клиента
- [ ] Остановленный мок во время `apply` даёт `502 APPLY_FAILED`, ничего не остаётся в остальных моках
- [ ] `apply` по одной компании не трогает другие компании и возвращает персону в исходное состояние, в том числе стирает выдачи и запросы в БКИ
- [ ] Пользовательская компания, созданная одним запросом, сразу видна во всех нужных моках бизнес-`GET`
- [ ] Журнал применения содержит запись по каждой системе
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)

## Тесты

Интеграционные тесты на живых четырёх мок-контейнерах (Testcontainers/compose): успех, сбой одного, повторный `apply`, пользовательская компания.

## Заметки для реализации

- Мок, который «не ответил», в тесте — это его остановка или режим `DOWN` ([T-106](T-106-mocks-chaos.md)); откат обязан работать и когда мок поднимется позже.
