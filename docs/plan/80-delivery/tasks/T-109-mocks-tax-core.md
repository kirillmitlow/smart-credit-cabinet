## Цель

Мок «Прозрачного бизнеса», ГИР БО, реестра МСП и статуса самозанятых. Из него `api` берёт налоговый долг, режим налогообложения, отчётность, категорию МСП и признание «самозанятый».

## Входит / не входит

- **Входит:**
  - `GET /api/v1/tax-profile/{inn}`: режимы, долги (`taxDebtRub`, пени, штрафы), доход, численность, флаги риска (массовый адрес, дисквалификация)
  - `GET /api/v1/financials/{inn}?year=`: 10 строк отчётности (форма простая/полная), `availableYears`; `404 STATEMENTS_NOT_FOUND` для ИП, самозанятого, компании моложе года и неподанного года; правило «последний год» из 2.5
  - `GET /api/v1/sme-status/{inn}`: `inRegistry: false` — это `200`, не `404`
  - `POST /api/v1/self-employed/status`: статус НПД; блока `meta` нет, вместо него заголовок `X-Mock-Simulated: true`
  - База `mock_tax`, миграции, `AdminHandler` с телом `taxProfile`, `financials[]`, `sme`, `npd`
- **Не входит:**
  - Госзакупки ЕИС ([T-110](T-110-mocks-tax-eis.md)), блокировки счетов ([T-111](T-111-mocks-tax-account-blocks.md))

## Критерии приёмки

- [ ] Примеры разделов 5.1–5.4 воспроизводятся, включая все коды ошибок
- [ ] Отчётность по любому верному 12-значному ИНН даёт `404 STATEMENTS_NOT_FOUND`, по неверному — `400 INN_INVALID`
- [ ] Запись отчётности с неверным балансом (`1600 ≠ 1100 + 1200`) отклоняется `422`
- [ ] `/api/v1/self-employed/status` ведёт себя по 5.4 и не содержит `meta`
- [ ] OpenAPI описывает все четыре эндпоинта и ошибки
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)

## Тесты

Тесты роли на вручную записанных данных: ООО с отчётностью, ИП без отчётности, самозанятый, компания моложе года, год не сдан.

## Заметки для реализации

- Баланс и согласованность «доход ПБ = строка 2110» проверяет валидатор сценариев ([T-126](T-126-mocks-consistency-rules.md)); мок обязан проверять только форму тела и баланс одной записи.
- Лимиты режимов (АУСН, УСН, патент) лежат в настройках, их значения 2026 года перед сдачей нужно сверить (вопрос Н-3 в спецификации).
