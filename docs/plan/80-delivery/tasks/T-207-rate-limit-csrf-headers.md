## Цель

Закрыть базовые требования безопасности из [50-09](../../50-architecture/09-security.md): лимит попыток входа и тяжёлых ручек, защита от CSRF для не-GET и безопасные заголовки.

## Входит / не входит

- **Входит:** свой счётчик в Redis (Q-063): вход 5/мин на связку ИНН+IP, автозаполнение 30/мин на сессию, загрузка 10/мин, остальное 300/мин; `429` + `Retry-After`; CSRF: cookie с токеном и проверка заголовка `X-CSRF-Token` на не-GET плюс проверка `Origin`; независимо для двух сессий; CSP, `X-Content-Type-Options`, `Referrer-Policy`, `frame-ancestors none`; CORS только из `CORS_ORIGINS`.
- **Не входит:** лимит кода подписи (3 попытки — в [T-211](T-211-one-time-codes.md)).

## Критерии приёмки

- [ ] Тест: 6-я попытка входа за минуту → `429 RATE_LIMITED` с `Retry-After`
- [ ] Тест: не-GET без CSRF-токена → 403; с токеном — проходит; GET не требует
- [ ] Лимиты и сессии клиента и банка независимы ([50-09](../../50-architecture/09-security.md), D-085)
- [ ] Лимиты лежат в настройках, а не в коде
- [ ] Тесты написаны и зелёные (`make check`)
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
