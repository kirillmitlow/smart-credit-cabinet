## Цель

Каркас сквозных тестов в браузере: вход, сброс, ожидания, доступность и артефакты падений. Сами тесты персон приходят вместе с экранами.

## Входит / не входит

- **Входит:**
  - `web/e2e/` с Playwright: Chromium, конфигурация для локального и CI запуска, базовый адрес, таймаут решения 90 с (в интерфейсе обещано «обычно до минуты»)
  - Фикстуры: вход клиента (ИНН → выбор пользователя → код с экрана, D-062), «Войти как андеррайтер», сброс персоны, две независимые сессии (клиент и банк, D-085)
  - `@axe-core/playwright` для проверки контраста и фокуса; поиск элементов по роли и подписи, а не по CSS
  - Трассы, видео и скриншоты при падении; один повтор только в CI; метки `TS-NNN`
  - Отдельный проект для хаос-тестов (последовательно, не параллелится)
- **Не входит:**
  - Сценарии персон (пишутся вместе с экранами)
  - Сопоставление с каталогом TS ([T-523](T-523-check-docs-ts-labels.md))

## Заметки для реализации

- Не используйте `data-testid`, если у элемента есть роль и подпись: так тест видит то, что видит человек.
- Playwright-браузеры кэшируются по версии в CI ([T-509](T-509-ci-skeleton.md)).
- Запуск: `WEB_PORT=8088 docker compose -p scc-pw up -d --build --wait`, затем `E2E_BASE_URL=http://localhost:8088 make -C web e2e` (один раз `make -C web e2e-install` ставит Chromium). `make check` и `make test` Playwright не запускают: Vitest читает только `src/`.
- Сброс персоны: `support/persona.ts`, функция `resetPersona`. Сейчас она только проверяет, что у персоны нет кредита и заявки в работе, и пропускает тест (в CI падает) с объяснением. Когда появится `POST /demo/personas/{code}/reset` ([T-372](T-372-demo-reset-persona.md)), вызвать его в этой функции (там стоит TODO).
- Тексты в тестах берутся из `web/src/texts` (`support/text.ts`), а не копируются. Правки подписей на экране не ломают тест, если слова меняются в словаре.
- `waitForStatus` и `markPageSession`/`expectNoReload` (`support/waits.ts`): ожидание без перезагрузки и без фиксированных пауз; метка в памяти окна пропадает, если страницу перезагрузили (RQ-05).
