## Цель

Признаки превращаются в 100 баллов по девяти факторам, затем в грейд A–E и PD; скоринг даёт только риск, решение принимают правила продукта (D-031).

## Входит / не входит

- **Входит:** раздел `scorecard`: интервалы «закрыты слева» → баллы по факторам `SC_AGE`, `SC_CREDIT_HISTORY`, `SC_INQUIRIES`, `SC_DEBT_LOAD`, `SC_TREND`, `SC_VOLATILITY`, `SC_TAX`, `SC_CLIENT`, `SC_COVERAGE`, значения «нет данных»; потолок грейда C (возраст < 6 мес., просрочка ≥ 60 дней за 24 мес., реструктуризация) с кодом `GRADE_CAPPED`; мастер-шкала: A 86–100 / PD 1%, B 74–85 / 3%, C 60–73 / 7%, D 46–59 / 15%, E 0–45 / 30%; режим PREVIEW: `SC_CREDIT_HISTORY`=16, `SC_INQUIRIES`=5, `SC_DEBT_LOAD`=7; вклад фактора = максимум − баллы (для объяснений).
- **Не входит:** пересчёт карты регрессией ([T-319](T-319-scorecard-recalibration.md)); допуск продукта по грейду ([T-294](T-294-rules-product-requirements.md)).
