## Цель

Правила только ставят флаги (D-034): расхождения источников и три паттерна по оборотам (накачка, транзит, один плательщик) с объяснением для андеррайтера.

## Входит / не входит

- **Входит:** `mismatch_turnover_fin`, `mismatch_declared`, `mismatch_statement` (> 30%), `flow_crosscheck_ratio` (< 0,5), директор анкеты ≠ реестр; накачка: `pump_ratio` ≥ 1,6 и модифицированный z ≥ 3,5, исключение сезонного повторения (≥ 24 мес., годом ранее те же 3 мес. относительно своей базы ≥ 1,3: чтение из «Расхождений» [30-17](../../30-decisioning/17-persona-walkthrough.md), чтобы 24-месячный ряд не подавлял накачку); транзит: ≥ 9 из 12 месяцев с долей списаний ≥ 0,985; один плательщик: ≤ 2 контрагентов 6 мес. подряд при ≥ 3 млн/мес, кроме ОКВЭД 47, 55, 56, 96; коды `DATA_MISMATCH`, `TURNOVER_ANOMALY` с параметрами (какое правило, значения).
- **Не входит:** сам маршрут «вручную» ([T-296](T-296-routing-authority.md)).

## Критерии приёмки

- [ ] Тесты на специально собранных рядах: накачка срабатывает, не срабатывает на сезонной `zarya`; транзит; один плательщик не срабатывает на кофейне Соколовой (ОКВЭД 56)
- [ ] Границы: расхождение 29,9% / 30,1%, коэффициент 0,49 / 0,5
