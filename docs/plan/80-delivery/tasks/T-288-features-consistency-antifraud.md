## Цель

Правила только ставят флаги (D-034): расхождения источников и три паттерна по оборотам (накачка, транзит, один плательщик) с объяснением для андеррайтера.

## Входит / не входит

- **Входит:** `mismatch_turnover_fin`, `mismatch_declared`, `mismatch_statement` (> 30%), `flow_crosscheck_ratio` (< 0,5), директор анкеты ≠ реестр; накачка: `pump_ratio` ≥ 1,6 и модифицированный z ≥ 3,5, исключение сезонного повторения (≥ 24 мес., годом ранее те же 3 мес. относительно своей базы ≥ 1,3: чтение из «Расхождений» [30-17](../../30-decisioning/17-persona-walkthrough.md), чтобы 24-месячный ряд не подавлял накачку); транзит: ≥ 9 из 12 месяцев с долей списаний ≥ 0,985; один плательщик: ≤ 2 контрагентов 6 мес. подряд при ≥ 3 млн/мес, кроме ОКВЭД 47, 55, 56, 96; коды `DATA_MISMATCH`, `TURNOVER_ANOMALY` с параметрами (какое правило, значения).
- **Не входит:** сам маршрут «вручную» ([T-296](T-296-routing-authority.md)).

## Критерии приёмки

- [x] Тесты на специально собранных рядах: накачка срабатывает, не срабатывает на сезонной `zarya`; транзит; один плательщик не срабатывает на кофейне Соколовой (ОКВЭД 56)
- [x] Границы: расхождение 29,9% / 30,1%, коэффициент 0,49 / 0,5
- [x] `t-mismatch` → `DATA_MISMATCH` (параметр моков 40 даёт 66,7% при знаменателе — отчётность); `t-anomaly` → `TURNOVER_ANOMALY`: ряд 18 мес., 15 по 5 млн и 3 по 9 млн, отношение 1,80, z = 10,79 ([30-17](../../30-decisioning/17-persona-walkthrough.md)); `zarya` не срабатывает (отношение 2,10, z = 1,74)
- [x] Выписка клиента даёт помесячные суммы, но не контрагентов: на ней работают только накачка и транзит
- [x] Тесты написаны и зелёные (`make check`)
- [x] Документация и OpenAPI обновлены, если менялся контракт (контракт не менялся; уточнения — [R-004](../../reviews/R-004-core-implementation-notes.md), пункты 7–13)
- [x] Запись в журнале

unit на собранных рядах + границы; property: флаги не отказывают сами.

## Заметки для реализации

- Пороги — допущения, живут в конфиге; уточняются на синтетическом портфеле (30-14), это правка конфига, а не документа ([30-02](../../30-decisioning/02-features-catalog.md)).
- Реализовано: признаки в `api/app/modules/decisioning/features.py` (`compare_with_financials`, `compare_declared`, `pump_stat`, `transit_months`, `payers_window`), пороги — раздел `flags` в `api/policy/v1.yaml`, сами флаги — `flags.py` ([T-290](T-290-rules-flags-young-business.md)). Все пороги и окна лежат в конфиге с `source`; у каждой проверки свой переключатель `enabled`.
- Накачка и транзит считаются на ряду, который служит источником выручки; «один плательщик» только на оборотах банка. Решения по пробелам — [R-004](../../reviews/R-004-core-implementation-notes.md), пункты 7–10.
