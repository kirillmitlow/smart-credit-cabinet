## Цель

Критерий «потенциал развития» (RQ-45) оценивает обоснование решений. Реестр D-NNN превращается в читаемую папку ADR — по одному файлу на решение — с индексом.

## Входит / не входит

- **Входит:**
  - Скрипт `scripts/build_adr.py`: разбирает таблицы реестра, создаёт `docs/adr/D-NNN-<slug>.md` по шаблону решения (контекст, решение, статус, последствия, источник), `docs/adr/README.md` с индексом и группами (организация, продукт, кредитное решение, архитектура)
  - Упоминание отмены/замены (например, D-033 заменено D-090) отражается в статусе
  - Решения со статусом 🟡 помечены «предложено, не подтверждено»
  - Скрипт запускается повторно без дублей; реестр остаётся источником правды
- **Не входит:**
  - Перепись решений вручную
  - Правка самого реестра

## Критерии приёмки

- [ ] Для каждого `D-NNN` из реестра есть файл ADR или явная причина пропуска
- [ ] Индекс группирует решения и ссылается на источники (документы плана, вопросы)
- [ ] Файлы ADR не содержат сгенерированного кода и укладываются в стандарт «без простыней»
- [ ] README ссылается на `docs/adr/` в разделе «Откуда взялись решения»
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)
