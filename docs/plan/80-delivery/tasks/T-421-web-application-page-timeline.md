## Цель

Главный экран продукта: шесть шагов таймлайна с подшагами проверки идут сами, блок исхода выбирается по `status`, видна подпись «обновляется автоматически».

## Входит / не входит

- **Входит:** вертикальный таймлайн из 6 шагов, подшаги «Проверяем данные» (реестр, налоговая, кредитная история) с галочками по мере выполнения, «Обычно до 1 минуты»; блок исхода по `status` и `allowedActions`; «Отозвать заявку» до подписания; состояния: идёт проверка, источник недоступен («Часть проверок затянулась, передали специалисту»), отозвана/истекла (конечное с пояснением), связь потеряна.
- **Не входит:** сами блоки исходов (T-422…T-425).
