## Цель

Все роли одинаково отвечают на ошибки, проверяют ключи и логируют запросы. Это «рельсы» для бизнес-эндпоинтов: любой следующий мок получает готовые правила 2.2–2.6 спецификации.

## Входит / не входит

- **Входит:**
  - `common/problems.py`: `ProblemException` и обработчики → `application/problem+json` с `code`, `requestId`; общие коды `INN_INVALID` (400), `UNAUTHORIZED` (401), `FORBIDDEN` (403), `VALIDATION_ERROR` (422, с `errors[]`), `RATE_LIMITED`, `SERVICE_UNAVAILABLE`
  - `common/auth.py`: `require_api_key` (свой ключ роли, чужой ключ → `401`, админ-ключ на бизнес-эндпоинте → `403`) и `require_admin` (`X-Admin-Key`)
  - `common/middleware.py`: `X-Request-Id` (принять или сгенерировать), случайная латентность из `MOCK_LATENCY_MS`, структурный JSON-лог (`ts`, `level`, `service`, `requestId`, `method`, `path`, `status`, `durationMs`, `chaos`), маскирование ИНН. Латентность не действует на `/health/*` и `/admin/*`
  - `common/schemas.py`: `CamelModel`, `Meta` (`source`, `simulated: true`, `requestId`, `retrievedAt`, `dataActualAt`), `Problem`; блок `meta` только у бизнес-API
  - Схемы безопасности OpenAPI `ApiKeyAuth` и `AdminKeyAuth` (кнопка Authorize в Swagger работает)
- **Не входит:**
  - Хук для chaos (место в цепочке middleware оставить, наполнит [T-106](T-106-mocks-chaos.md))
  - Идемпотентность ([T-104](T-104-mocks-common-idempotency.md))

## Критерии приёмки

- [ ] Тестовый эндпоинт-заглушка отвечает так, как описано в 2.4: `400` только для неверного ИНН, `422` для остального, `401` для чужого ключа, `403` для админ-ключа не на своём месте
- [ ] Ошибка любого вида — `problem+json` с полями `type`, `title`, `status`, `code`, `requestId`
- [ ] Каждый ответ содержит `X-Request-Id`; пришедший заголовок возвращается без изменений
- [ ] В логе нет полного ИНН, ФИО и номеров счетов
- [ ] Swagger роли показывает кнопку Authorize и обе схемы безопасности
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)
