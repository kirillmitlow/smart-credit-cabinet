## Цель

Общие помощники для тестов «персона проходит путь без браузера»: сбросить, войти, подать, дождаться, сверить с ожидаемым исходом сценария.

## Входит / не входит

- **Входит:**
  - Фикстуры для `api/tests/personas/`: сброс одной персоны (по Q-105: `POST /demo/personas/{code}/reset` либо `apply` + чистка данных `api`), вход по ИНН и коду из демо-режима, ожидание статуса с таймаутом и опросом (без `sleep`)
  - Ожидаемые исходы берутся из `GET /scenarios` (`expectedOutcome`, `expectedFinalOutcome`, `expectedReasonCodes`), а не копируются в код
  - Параметризация по всем 9 персонам и 10 техническим сценариям
  - Метка `TS-NNN` на каждом тесте и проверка схемы ответа
  - Хелпер сдвига «сегодня» для сценариев со временем
- **Не входит:**
  - Сами тесты персон (по месту)
  - Playwright ([T-518](T-518-playwright-harness.md))

## Критерии приёмки

- [ ] Один пример-тест для `sokolova` проходит от сброса до ожидаемого исхода
- [ ] Параметризация по списку сценариев строится из ответа мока, а не из константы
- [ ] Хелпер ожидания падает с понятным текстом, показывая последний статус и таймлайн
- [ ] Повторный запуск того же теста подряд даёт тот же результат (сброс работает)
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)
