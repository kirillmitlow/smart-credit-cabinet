## Цель

Три зоны одного SPA (`/login` и клиент, `/bank/*`, `/demo`) с ленивой загрузкой банка и демо и защитой по ролям; интерфейс скрывает лишнее, решает сервер.

## Входит / не входит

- **Входит:** React Router 7, карта адресов клиента и банка из [60-01](../../60-frontend/01-app-structure.md), шаг заявки в адресе, одна страница заявки на все статусы; `GET /me` и `GET /public-config` при старте, редирект на `/login` с запоминанием адреса, выбор активной компании; экраны «Эта часть для сотрудников банка» (клиент зашёл на `/bank`), «Не нашли такую заявку» (`404`), общий экран ошибки с `requestId` и «Повторить»; `/demo` при выключенном демо — «Не найдено»; кнопки строятся из `allowedActions`, а не из копии стейт-машины.
- **Не входит:** содержимое экранов (T-408…T-435).

## Критерии приёмки

- [ ] Клиент по `/bank` видит понятный экран, а не тихий редирект
- [ ] При `DEMO_MODE=false` нет пункта меню и адреса `/demo`
- [ ] Код зоны банка не скачивается клиентом (отдельные чанки)
- [ ] Чужая заявка (`404`) → общий экран
- [ ] Тесты написаны и зелёные (`make check`)
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
