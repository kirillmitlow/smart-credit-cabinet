## Цель

Закрыть пробел T-001: независимая разметка и подборка для калибровки порогов по слотам, закрытая подборка для проверки; цели ≥ 95% для автоподстановки остаются критерием, а не измеренным свойством.

## Входит / не входит

- **Входит:** ≥ 120 фраз: подборка для порогов и закрытая; разговорный язык, сленг, опечатки, два дела сразу, противоречия, не про кредит, «команды»; таблица метрик (точность по слотам, в зоне «принято», доля закрытых без кнопок, p50/p95, память).
- **Не входит:** автоподстановка без подтверждения (не включается).
