## Цель

Клиент готовит ответы (файл или текст), нажимает «Отправить ответ банку» — все задачи раунда уходят разом, создаётся версия `INFO_PROVIDED`, заявка идёт `NEEDS_INFO → CHECKING`.

## Входит / не входит

- **Входит:** `POST /tasks/{id}/answer` (черновик ответа не виден банку), замена файла (старый помечается недействительным); отправка раунда: все задачи → `ANSWERED`, версия `INFO_PROVIDED`, переход и запуск конвейера в одной транзакции по ключу «версия + событие»; не более 3 раундов, затем обязательный ручной разбор (Q-127, D-091); отказ поручителя → `CANCELLED(GUARANTOR_DECLINED)` и новая задача.
- **Не входит:** повторный прогон ([T-277](T-277-pipeline-rerun-flows.md)).
