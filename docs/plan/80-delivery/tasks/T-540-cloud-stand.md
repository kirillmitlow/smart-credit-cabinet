## Цель

Облачная публикация желательна (RQ-12). VPS разрешён (D-067). Задача заблокирована ответом на Q-008 (где арендуем), поэтому может не состояться; README в любом случае ведёт жюри на локальный запуск.

## Входит / не входит

- **Входит:**
  - Подготовка VPS по 50-14: пользователь без root, файрвол (22, 80, 443), Docker Engine, клон нужной версии, `.env` с настоящими секретами (генерирует и хранит пользователь)
  - Запуск с `docker-compose.cloud.yml`, проверка `/health/ready`, `smoke.sh` с локальной машины, проверка закрытых портов, HTTPS
  - Бэкап `pg_dump` ночью и проверка после перезагрузки
  - Ссылка и код стенда (для сброса и сбоев, D-086) в README
- **Не входит:**
  - Покупка VPS (действие пользователя) и ввод секретов (только пользователь)

- [ ] Стенд открывается по HTTPS, `smoke.sh` зелёный
- [ ] Порты моков и `api` снаружи закрыты (проверено сканированием)
- [ ] Секреты не попали в репозиторий и в логи; код стенда выдан только через README
- [ ] Ссылка и дата проверки записаны в README
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)
