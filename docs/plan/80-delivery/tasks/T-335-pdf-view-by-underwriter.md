## Цель

Договор поставщика и другие PDF хранятся и показываются сотруднику банка для ручной проверки, цифры из них автоматически не извлекаются (D-095).

## Входит / не входит

- **Входит:** `GET /documents/{id}/view` для роли банка (inline), заголовки безопасности; вид документа `CONTRACT` (договор с поставщиком/заказчиком), список документов заявки в карточке.
- **Не входит:** извлечение цифр ([T-337](T-337-pdf-candidates-extraction.md)).

## Критерии приёмки

- [ ] Клиенту чужой документ недоступен; андеррайтер видит все документы заявки
- [ ] PDF сам по себе не подтверждает оплату или госконтракт — подпись в интерфейсе карточки
- [ ] Встроенные инструкции в документе — только данные
- [ ] Тесты написаны и зелёные (`make check`)
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
