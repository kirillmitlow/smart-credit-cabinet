## Цель

Клиент отзывает заявку до подписания; отзыв выполняется только с подтверждением, закрывает задачи и сообщает в БКИ (`WITHDRAWN`).

## Входит / не входит

- **Входит:** `POST /applications/{id}/withdraw` (с флагом подтверждения), переходы `* → WITHDRAWN` по [20-02](../../20-process/02-application-states.md); после `SIGNED` отзыв запрещён (`409`); открытые задачи → `CANCELLED`, событие, outbox `APPLICATION_DECIDED = WITHDRAWN` при условии из [20-05](../../20-process/05-disbursement-and-after.md).
- **Не входит:** отзыв согласия ([T-262](T-262-consent-revocation.md)).

## Критерии приёмки

- [ ] Отзыв без подтверждения не выполняется молча (D-092)
- [ ] После `SIGNED` — `409 INVALID_TRANSITION`
