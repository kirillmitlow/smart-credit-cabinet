## Цель

Клиент видит кредит и график, совпадающий с графиком предложения до рубля; платежи и просрочки не моделируются.

## Входит / не входит

- **Входит:** `loans`, `payment_schedule` (статус только `SCHEDULED`), `GET /loans`, `GET /loans/{id}`, `GET /loans/{id}/schedule`; ближайший платёж по календарю с переносом на рабочий день; для `BULLET` — проценты и долг в конце; для линии и овердрафта — лимит и ставка без графика (D-093); права: руководитель и сотрудник; поручитель — только своё поручительство (просмотр); андеррайтер видит кредит в карточке заявки.
- **Не входит:** запись из выдачи ([T-342](T-342-disbursement-workflow.md)).

## Критерии приёмки

- [ ] Итог графика = долг + проценты; платёж на карточке = платёж в графике
- [ ] Остаток долга равен выданной сумме, как в АБС
- [ ] Чужая компания → `404`
- [ ] Тесты написаны и зелёные (`make check`)
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
