## Цель

Ядро определяет, кто решает: автомат одобряет, когда всё хорошо и в пределах полномочий, и отправляет человека всё сомнительное; указывает требуемый уровень L1/L2.

## Входит / не входит

- **Входит:** таблица маршрута из семи правил [30-11](../../30-decisioning/11-routing-and-authority.md) (сверху вниз), ручные причины `AMOUNT_ABOVE_AUTO_LIMIT`, `COLLATERAL_REVIEW`, `GRADE_NEEDS_REVIEW`, `NEAR_THRESHOLD`, любой флаг; серые зоны: баллы 74–75 и 44–45, DSCR [1,25; 1,30), стресс-DSCR [1,00; 1,05), долг/выручка 0,95–1,00 — все в конфиге; матрица полномочий (сумма × грейд → L1/L2), `required_level`; исключение из политики — всегда L2; уточнение C-04: встречные считаются и проверяются каждое по своим условиям; превышение авто-лимита в исходном запросе не блокирует автоматическое встречное в пределах полномочий; если автоматического варианта нет, но есть выше полномочий — `MANUAL_REVIEW`; если нет вообще — `NO_OFFER_FOUND`; `recommended_outcome` для каждого `MANUAL_REVIEW`: что решило бы ядро без ручных триггеров.
- **Не входит:** построение встречных ([T-297](T-297-counter-offers-optimizer.md)); применение переопределений андеррайтера ([T-362](T-362-backoffice-decision.md)).

## Критерии приёмки

- [ ] Таблица маршрута — по тесту на строку и на пересечения (флаг + грейд C)
- [ ] Границы серой зоны: DSCR 1,2499 / 1,25 / 1,2999 / 1,30; баллы 73 / 74 / 75 / 76
- [ ] Персоны: `sokolova` авто `APPROVED`; `snabkontrakt` авто `COUNTER_OFFER`; `stankoprom`, `zarya` — `MANUAL_REVIEW`; `quick-start` — условное встречное; `stankoprom` (15 млн, A) — L1, `zarya` (20 млн) — L2, `quick-start` (1 млн, C) — L1
- [ ] Property: ни один вариант встречного не попадает в серую зону и не превышает авто-лимит
- [ ] Конкретные числа СнабКонтракта — по [30-17](../../30-decisioning/17-persona-walkthrough.md), а не по черновым «8 млн против 5 млн»
- [x] Флаги из [T-290](T-290-rules-flags-young-business.md) подключаются по мере готовности: ручной маршрут принимает список флагов на входе
- [ ] Тесты написаны и зелёные (`make check`)
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале

## Тесты

unit: полная таблица; property: инварианты встречных; персоны.
