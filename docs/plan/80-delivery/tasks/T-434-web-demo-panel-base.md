## Цель

Жюри проверяет прототип само: панель отвечает «под кем входить, что ждать, как посмотреть банк». Существует только при `DEMO_MODE`.

## Входит / не входит

- **Входит:** страница `/demo` и выдвижная панель-язычок в углу любой зоны; блок персон: что просит, ожидаемый исход и коды, «что дальше» (данные из `GET /demo/personas`), без кнопки входа — «ИНН в README»; технические сценарии свёрнуты; «Войти как андеррайтера» (и в админа), ссылки на Swagger `api` и моков из `/public-config`; сворачиваемая подсказка «ожидаемый исход» на странице заявки (закрыта по умолчанию, D-087).
- **Не входит:** сброс и сбои ([T-435](T-435-web-demo-reset-chaos.md)).

## Реализация B, 23.10.2026

Страница /demo и общий drawer в RootLayout (клиентские файлы A не менялись). Персоны динамические: после слияния T-133 все девять исходных персон A появились без изменения панели. Технические свёрнуты. Вход UNDERWRITER/ADMIN открывает новую вкладку, sid_client остаётся. Outbox доступен ссылкой в банковскую зону. Swagger-ссылки из public-config.docsLinks/DOCS_LINKS, по умолчанию только /docs API. C должен опубликовать и настроить ссылки четырёх моков; админ-ключи не передаются.


**Граница загрузки, B 23.10.** Прямой переход /demo при выключенной публичной настройке показывал 404, но RouteObject.lazy успевал загрузить DemoZoneLayout/DemoPanel до RequireDemo. Браузерный тест воспроизвёл эти запросы. Компоненты переведены на React.lazy внутри защищённого Outlet: при выключенном демо нет загрузки модулей панели и запросов /demo/*. Собранный стенд: пять браузерных проверок прошли, включая включённую панель, сбой/сброс, подсказку и независимый вход банка. Здесь проверяется загрузка браузером; серверный DEMO_MODE отдельно проверен интеграционно. Настройка ссылок моков остаётся C.

При пустом каталоге добавлена кнопка обновления: после старта сервиса сценариев список можно загрузить без обновления страницы. Компонентные проверки покрывают пустой каталог, недоступный каталог с повтором и независимое отображение доступности источников.

**Живой каталог после T-133:** собственный scc-bank обновлён свежими моками A, startup API синхронизировал все компании. В ответе девять встроенных персон и прежний синтетический b-t370-check; TS-101 проверил заголовок и ожидаемый исход каждой нетехнической карточки, затем сбой, восстановление и сброс. Все проверки прошли; это проверка отображения данных API, не повторная оценка банковского оракула.
