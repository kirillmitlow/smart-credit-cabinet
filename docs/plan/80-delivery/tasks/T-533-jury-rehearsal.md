## Цель

Агент проходит сценарий так, как будет делать жюри: клон, `docker compose up`, шаги README, фиксация находок и времени. Результат — список правок README и интерфейса.

## Входит / не входит

- **Входит:**
  - Клон репозитория в чистую папку, запуск строго по README (без знаний из истории), хронометраж каждого шага
  - Список находок: непонятные формулировки, лишние шаги, расхождения README и интерфейса, ошибки
  - Правки README внесены в этой же задаче; ошибки продукта оформлены задачами или вопросами
  - Итоговое время прохождения записано в README (раздел «Сколько займёт»)
- **Не входит:**
  - Проверка на Windows ([T-536](T-536-windows-check-pack.md)) и юзабилити-тесты ([T-537](T-537-usability-pack.md))

## Критерии приёмки

- [ ] Весь сценарий пройден без обращения к документам плана и без чтения кода
- [ ] Каждый шаг имеет зафиксированное время; сумма в пределах 30 минут
- [ ] Находки с влиянием «мешает» и выше исправлены до заморозки или записаны как известные ограничения
- [ ] Отчёт репетиции (таблица шагов) приложен к PR и журналу
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)
