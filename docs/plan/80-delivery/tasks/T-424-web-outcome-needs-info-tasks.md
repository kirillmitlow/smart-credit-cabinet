## Цель

Запрос банка оформлен задачей «что, зачем, срок, где взять»; выписку 1С можно перетащить, а в демо — сгенерировать кнопкой. Ответы раунда отправляются разом.

## Входит / не входит

- **Входит:** карточка «Нужна ваша помощь» (заголовок, зачем, что именно, где взять, срок только при включённом таймере); зона «Перетащите файл 1С», понятные ошибки файла («Это выписка другой компании», «Период короче 3 месяцев», «Суммы не сходятся»), замена файла без потери задачи; кнопка «Сгенерировать тестовую выписку» — только при `DEMO_MODE`; «Отправить ответ банку» отправляет все задачи раунда, пояснение, поле ответа текстом.
- **Не входит:** согласие поручителя ([T-425](T-425-web-outcome-manual-guarantor.md)).

## Реализация (23.10.2026, часть)

- `NeedsInfoPanel` на странице заявки в `NEEDS_INFO`: номер раунда «из трёх», у каждой задачи зачем, что именно, где взять, срок («не ограничен» или «до …»), кто отвечает, поле текста. Служебные коды (`kind`, `reasonCode`) клиенту не показываются.
- «Сохранить черновик» шлёт `POST /tasks/{id}/answer`; «Отправить ответы» доступна, когда в каждой своей задаче есть текст (а чужие задачи уже отвечены), сохраняет несохранённое и зовёт `POST /applications/{id}/tasks/submit`. Повторные нажатия игнорируются, пока идёт запрос. После отправки страница сама перечитывает заявку и показывает «Проверяем заново».
- Поручитель видит только свою задачу и кнопку «Сохранить ответ»; раунд отправляет не он.
- Главная: «Что нужно от вас» берёт открытые задачи из `GET /applications/{id}/tasks` (строка на задачу, ссылка на заявку); пока задачи не загрузились, остаётся общая строка.
- Файл 1С: пока не загружается, на задаче с документом честно написано, что загрузка появится позже. Кнопки-пустышки нет.
- Не сделано: перетаскивание файла и ошибки файла («другая компания», «период короче 3 месяцев», «суммы не сходятся»), замена файла, «Сгенерировать тестовую выписку» (только `DEMO_MODE`, T-373), «Сделать позже».
