## Цель

Видимая надёжность: рестарт воркера и Redis посреди проверки не ломает заявку, «уронить БКИ» ведёт к ручному разбору с понятными сообщениями.

## Входит / не входит

- **Входит:** рестарт `worker`, затем `redis` посреди проверки: заявка доходит до итога, вход не слетает (TS-066, TS-067); демо-панель: «Уронить БКИ» → заявка на ручное → «починить» → «перепроверить» (TS-060); отдельный последовательный проход (не параллелить с остальными).
- **Не входит:** нагрузка Locust ([T-520](T-520-locust-harness.md)).
