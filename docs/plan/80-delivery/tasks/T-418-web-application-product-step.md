## Цель

Спрашиваем только нужное для продукта: контракт из списка ЕИС (`CONTRACT`), залог «то, что покупаю» (`INVESTMENT`), поручитель для молодого бизнеса.

## Входит / не входит

- **Входит:** выбор контракта из `GET /companies/{id}/gov-contracts`, форма залога (описание и оценка), выбор/приглашение поручителя; для остальных продуктов шаг пропускается.
- **Не входит:** согласие поручителя ([T-425](T-425-web-outcome-manual-guarantor.md)).
