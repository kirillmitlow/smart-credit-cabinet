## Цель

Отчёт синтетического прогона (Gini, KS, PSI, калибровка, доли исходов) доступен жюри как артефакт и как сводная таблица. Это ответ на RQ-67 «проверка качества модели».

## Входит / не входит

- **Входит:**
  - Загрузка `synthetic-report` (JSON, markdown, картинки) артефактом на 14 дней; краткая таблица проверок в `$GITHUB_STEP_SUMMARY`
  - Скрипт `scripts/build_quality_table.py`: собирает таблицу «Качество» (число тестов, покрытие, метрики синтетики, seed, версия правил и имитатора) из артефактов в markdown для README
  - Копия отчёта последнего зелёного `main`/тега кладётся в `docs/` (путь решает [T-531](T-531-readme-generated.md))
  - Оговорка из 30-06 в отчёте: метрики показывают механику, а не реальную предсказательную силу
- **Не входит:**
  - Сам имитатор и отчёт (задачи ядра)
