## Реализация B, 23.10.2026

Корневая подсказка на /applications/:id только в DEMO_MODE; закрыта по умолчанию, ожидаемый исход берётся из сценария. Совпадают companyId, продукт, сумма и срок; текст поясняет влияние иных данных и отдельный расчёт фактического решения. Кэш заявки использует тот же формат generated API, что клиентский экран. Нужна итоговая браузерная сверка на всех девяти исходных персонах после слияния данных A.
