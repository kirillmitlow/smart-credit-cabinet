## Реализация B, 23.10.2026

Корневая подсказка на /applications/:id только в DEMO_MODE; закрыта по умолчанию, ожидаемый исход берётся из сценария. Совпадают companyId, продукт, сумма и срок; текст поясняет влияние иных данных и отдельный расчёт фактического решения. Кэш заявки использует тот же формат generated API, что клиентский экран. Браузерная проверка на исходной Соколовой: закрытое состояние, раскрытие ожидаемого исхода из API, повторное сворачивание и axe. После изменения суммы подсказка скрывается. Vitest отдельно подтверждает отсутствие подсказки и запроса каталога вне DEMO_MODE. Проверка чисел всех девяти персон относится к данным и оракулу A; компонент не рассчитывает кредитное решение.
