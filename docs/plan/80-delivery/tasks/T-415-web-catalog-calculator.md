## Цель

Клиент смотрит шесть продуктов и считает платёж двумя ползунками; недоступный продукт серый с «станет доступен после…».

## Входит / не входит

- **Входит:** сетка карточек (для чего, сумма, срок, залог, кому доступно), калькулятор «платёж / переплата / ставка от…» с пометкой «ориентировочно»; ввод без запроса на каждую цифру (пауза), значения вне рамок — подсказка, запрос не уходит.
- **Не входит:** заявка (T-416…).

- [ ] Значения приходят из `POST /calculator/payment`, на фронте нет формул
- [ ] Формат `500 000 ₽`, проценты с запятой
- [ ] Сбой сервера — текст из словаря
