## Цель

Архитектурная схема — обязательный артефакт (RQ-17). Диаграмма контейнеров из 50-01 выгружается в картинку, которую видно в README и в `docs/architecture/`.

## Входит / не входит

- **Входит:**
  - `scripts/export_diagrams.sh` (mermaid-cli, фиксированная версия, запуск в контейнере, без установки на хост): `*.mmd` → SVG и PNG
  - `docs/architecture/architecture.mmd` (из 50-01 с актуализацией по реальным контейнерам и профилям `ai`, `obs`) → `architecture.svg`, `architecture.png`
  - Подпись к схеме: что внутри, цвета, где граница стенда; ссылка на 50-01
  - Команда `make diagrams`
- **Не входит:**
  - Диаграмма состояний ([T-526](T-526-diagram-states.md)), ER ([T-527](T-527-diagram-er.md))
