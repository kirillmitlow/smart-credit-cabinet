## Цель

Андеррайтер и админ входят одной кнопкой (D-010), единственный демо-вход даёт уровень L2, а ограничения L1 проверяются API-тестами (D-090, Q-110).

## Входит / не входит

- **Входит:** `POST /auth/bank-demo-login` (только при `DEMO_MODE`), роль `UNDERWRITER`/`ADMIN`, уровень L2; поле уровня у пользователя банка; тестовый пользователь L1 создаётся фикстурой; `audit.record` для входов и выходов банка.
- **Не входит:** матрица решений по уровням ([T-362](T-362-backoffice-decision.md)).

## Критерии приёмки

- [ ] Вне `DEMO_MODE` ручка отвечает `403 DEMO_MODE_DISABLED`
- [ ] Клиентская сессия не даёт доступа к банковским ручкам и наоборот
- [ ] В `Principal` банка есть `level`; фикстура L1 доступна тестам
- [ ] Тесты написаны и зелёные (`make check`)
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале

## Тесты

integration: вход, выход, независимость двух сессий; негативные тесты зон.
