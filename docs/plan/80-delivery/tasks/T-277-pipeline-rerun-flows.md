## Цель

`NEEDS_INFO → CHECKING` и `MANUAL_REVIEW → CHECKING` запускают новый прогон на свежих данных; платный отчёт БКИ не покупается заново; счётчик раундов уходит в обязательный ручной разбор.

## Входит / не входит

- **Входит:** новая версия `INFO_PROVIDED`, ключ запуска (версия + событие) против двойного нажатия, статус и запуск в одной транзакции; пометки «получен документ» и «клиент ответил»; сообщение «правила обновлены» при смене политики; после третьего раунда ядро/конвейер направляет заявку на обязательный ручной разбор, не обязывая одобрять (D-091).
- **Не входит:** создание задач ([T-350](T-350-client-tasks-create.md)); ответ клиента ([T-351](T-351-client-tasks-answer-round.md)).
