## Цель

Schemathesis читает OpenAPI и сам придумывает странные запросы, находит `500` и ответы не по схеме (Q-103, D-088).

## Входит / не входит

- **Входит:**
  - Конфигурация запуска против поднятого стенда: сессия директора и отдельный прогон под андеррайтером; в PR — 50 примеров на ручку, ночью — 500
  - Что считается ошибкой: `5xx` (кроме осознанного `503` при сбое), ответ не по схеме, неописанный код, неверный `Content-Type`
  - Исключения с комментарием «почему»: `/demo/reset`, `/demo/chaos`, `GET /events` (поток), загрузка файлов
  - Ночной прогон против моков: на странный ввод мок обязан отвечать `422`, а не `500`
  - Команда `make fuzz`
- **Не входит:**
  - Собственные тесты критических действий (отдельные тесты `api`)
