## Цель

Из PDF с текстовым слоем предлагаются кандидаты строк 2110, 2330, 2400 и года; сотрудник подтверждает до использования. Скан без текста — «не удалось извлечь», не нули.

## Входит / не входит

- **Входит:** pypdf для текста (Q-140, рекомендация A), кандидаты: значение, единица (рубли/тысячи), год, страница, строка, фрагмент-основание; подтверждение сотрудником, конфликт с ГИР БО решается приоритетом 30-03 и флагом сверки.
- **Не входит:** OCR сканов (вне MVP).

## Критерии приёмки

- [ ] Нельзя взять выручку прошлого года за текущую, потерять множитель 1000 или считать отсутствие текста нулевой выручкой
- [ ] Без подтверждения данные в решение не идут
- [ ] Корпус независимых документов с проверенными строками и единицами
