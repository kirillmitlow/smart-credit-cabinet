## Цель

Доказать, что `docker compose up` по README работает на машине без наших кэшей и настроек (RQ-11, RQ-53). Автоматизированный прогон + офлайн-проверка.

## Входит / не входит

- **Входит:**
  - Чистая среда (виртуальная машина или контейнер с Docker, без кэша образов и томов), клонирование, запуск строго по README, `scripts/smoke.sh`, `docker stats`
  - Офлайн-проверка: после первой сборки отключить сеть, сделать `down -v`, `up`, пройти сценарий; во время работы ничего не скачивается (ни пакеты, ни шрифты, ни модели)
  - Проверка без `.env` и без `make`
  - Скрипт `scripts/clean_machine_check.sh` для повторения; отчёт с датой, железом, временем сборки и запуска
- **Не входит:**
  - Проверка на Windows (команда, [T-536](T-536-windows-check-pack.md))
