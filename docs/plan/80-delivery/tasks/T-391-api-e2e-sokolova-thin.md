## Цель

Автотест на помощниках [T-517](T-517-personas-api-harness.md) доказывает, что тонкий сквозной сценарий (10-05) работает: вход по ИНН и коду → мастер → заявка → согласия → конвейер → `APPROVED` → клиентское решение. Это приёмка готовности тонкого пути на уровне API.

## Входит / не входит

- **Входит:** тест по HTTP на живом compose с моками (маркер `persona`), `apply` сценария перед прогоном; проверка последовательности событий таймлайна и клиентского решения без внутренних полей; ожидание решения с таймаутом 90 с, без `sleep` по времени.
- **Не входит:** остальные персоны ([T-392](T-392-api-persona-tests.md)); браузерные e2e ([T-518](T-518-playwright-harness.md), [T-512](T-512-ci-e2e.md)).
