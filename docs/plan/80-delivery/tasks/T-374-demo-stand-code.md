## Цель

Локально демо-панель открыта, в облаке сброс и включение сбоев требуют короткий код стенда из README — барьер от случайного нажатия, не защита личности (D-086).

## Входит / не входит

- **Входит:** проверка кода на сервере, ограничение частоты; не распространяется на админ-API моков и рабочее место банка.
- **Не входит:** интерфейс ввода кода ([T-435](T-435-web-demo-reset-chaos.md)).
