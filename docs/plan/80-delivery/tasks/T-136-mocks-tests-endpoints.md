## Цель

Тесты уровня «каждый мок против каждой персоны». Закрывают первую часть раздела 11 спецификации (на уровне задач отдельных ролей остаются только их локальные тесты).

## Входит / не входит

- **Входит:**
  - Для каждой встроенной персоны каждый эндпоинт отдаёт данные, согласованные со сценарием; у всех 19 сценариев есть `expectedOutcome` из перечня исходов и `expectedReasonCodes`, а у 9 персон и `application`
  - `400` только на неверный ИНН, `422 VALIDATION_ERROR` на остальное, `404` и `200` с пустым списком по правилу из 2.4; отчётность ИП → `404 STATEMENTS_NOT_FOUND`; чужой ключ → `401`, ключ не того раздела → `403`
  - ЕФРСБ: нет дел → `200` с пустым списком; `t-bankrupt`: дело у учредителя и такое же в БКИ
  - ЕИС: контракт у СнабКонтракта, `contracts: []` у остальных
  - Каждый тест помечен маркером `mocks` (и меткой `TS-NNN`, если есть в [70-09](../../70-quality/09-test-scenarios-catalog.md))
- **Не входит:**
  - Арифметика БКИ и идемпотентность АБС ([T-137](T-137-mocks-tests-bki-bank.md)), chaos и синхронизация ([T-138](T-138-mocks-tests-chaos-sync.md))
