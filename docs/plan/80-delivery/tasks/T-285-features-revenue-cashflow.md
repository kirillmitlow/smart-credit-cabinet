## Цель

Из снимка данных ядро считает осторожную выручку и свободный поток по приоритету источников (оборот нашего банка → отчётность ГИР БО → выписка клиента → `REVENUE_UNKNOWN`) с поправкой на НДС по дате месяца.

## Входит / не входит

- **Входит:** `vat_rate(m)` (20% до 31.12.2025, 22% с 01.01.2026, только ОСНО), `turnover_net_series`; `revenue_cautious_rub`: минимум из средних за 12 и 6 мес.; сезонным — год / 12; меньше 6 мес. — среднее × 0,7; из отчётности — 2110 / 12; `flow_model_rub`: по свежей отчётности (прибыль + проценты) × `min(1, выручка_осторожная / (2110/12))`, иначе выручка × маржа отрасли; отрицательный поток = 0; маржа отрасли по ОКВЭД (торговля 5%, общепит 10%, производство 12%, IT 15%, агро 15%, услуги 13%), `industry_group`, `flow_observed_rub`; качество источника на каждом признаке (`OWN_BANK`, `OFFICIAL`, `CLIENT_UPLOAD`, `ESTIMATE`).
- **Не входит:** тренд и волатильность ([T-287](T-287-features-trend-volatility.md)); сверка ([T-288](T-288-features-consistency-antifraud.md)); признаки БКИ и налогов ([T-286](T-286-features-bureau-tax-company.md)).

## Критерии приёмки

- [ ] Эталоны [30-17](../../30-decisioning/17-persona-walkthrough.md): `sokolova` выручка 905 000, поток 90 500; `snabkontrakt` выручка 15 000 000 без НДС, поток по отчётности (13 200 000 + 1 200 000) / 12 = 1 200 000; `garipov` по выписке выручка 700 000, поток 91 000; `quick-start` выручка 700 000 × 0,7 = 490 000, поток 73 500; `zarya` сезонная, выручка 54 166 667, поток 5 750 000; `stankoprom` выручка 35 000 000, поток 2 716 667
- [ ] Нет данных ≠ ноль: ни одного источника → `REVENUE_UNKNOWN`, а не нулевая выручка
- [ ] НДС делится по дате месяца: ряд на 24 месяца через 2025/2026 считается верно
- [ ] INV-33: осторожная выручка ≤ каждого из средних за 12 и 6 мес.; добавление НДС не меняет чистую выручку
- [ ] Тесты написаны и зелёные (`make check`)
