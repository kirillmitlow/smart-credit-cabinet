## Цель

Решение по заявке всегда на свежих данных (Q-038): конвейер получает клиента без доступа к кэшу, автозаполнение — с кэшем в Redis; ошибиться параметром нельзя, потому что параметра нет.

## Входит / не входит

- **Входит:** `FreshGateway` и `CachedGateway`, срок кэша по таблице [50-08](../../50-architecture/08-integration-adapters.md) (24 ч реестр и ФНС, 7 дней отчётность); ключи `lookup:{система}:{ресурс}:{ИНН}`, сброс префикса `lookup:` при сбросе стенда.
- **Не входит:** кэш отчётов БКИ (его нет).
