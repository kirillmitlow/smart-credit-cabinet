## Цель

Все 9 персон и 10 технических сценариев проходят `decide()` без сети и дают ожидаемые исходы и коды (таблица покрытия стоп-факторов из [10-02](../../10-product/02-personas.md)).

## Входит / не входит

- **Входит:** `snabkontrakt`, `stankoprom`, `garipov`, `orlov`, `zarya`, `quick-start`; `t-aml`, `t-gambling`, `t-mass`, `t-overdue-45`, `t-overdue-95`, `t-tax-debt`, `t-mismatch`, `t-young-collateral`, `t-anomaly`, `t-bankrupt`; ожидаемые исходы и коды из [10-02](../../10-product/02-personas.md), финальные исходы цепочек; для ряда `t-anomaly` — детерминированный ряд из моков.
- **Не входит:** прогон по API ([T-392](T-392-api-persona-tests.md)).
