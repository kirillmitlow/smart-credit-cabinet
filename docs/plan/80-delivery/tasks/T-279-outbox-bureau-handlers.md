## Цель

БКИ получает события жизненного цикла заявки вовремя и без дублей: `APPLICATION_REGISTERED`, `APPLICATION_DECIDED`, `WITHDRAWN`, `OBLIGATION_OPENED`.

## Входит / не входит

- **Входит:** таблица правил из [20-05](../../20-process/05-disbursement-and-after.md): когда какое событие, `eventId` постоянный от (заявка, тип); встречное предложение ничего не отправляет до решения клиента; принятие встречного → `APPROVED` (Q-022); отказ клиента/истечение → `WITHDRAWN`; `NEEDS_INFO` и `MANUAL_REVIEW` в БКИ ничего не меняют; мок должен допускать повторное событие по той же заявке: сверить с реализацией моков.
- **Не входит:** `OBLIGATION_OPENED` при выдаче (вызывается из [T-342](T-342-disbursement-workflow.md)).
