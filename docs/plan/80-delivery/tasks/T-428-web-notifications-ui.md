## Цель

Клиент и сотрудник банка ничего не пропустят внутри продукта: счётчик, список, тост 6 секунд только там, где нужно действие.

## Входит / не входит

- **Входит:** колокольчик со счётчиком в шапке обеих зон, выпадающий список и страница `/notifications`, «Прочитать все»; тост по SSE (`task_created`, решение, просьба поручителю) — при активной вкладке, не повторяется при возврате; уведомление ведёт на конкретный экран; отдельный список событий банка.
- **Не входит:** правила и тексты уведомлений (бэкенд [T-354](T-354-notifications-client.md)).
