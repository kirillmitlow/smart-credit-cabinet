## Цель

Ядро не противоречит себе ни на одном из тысяч реалистичных входов: монотонность, граничные условия, встречные, детерминизм и правила.

## Входит / не входит

- **Входит:** сводные тесты INV-01…INV-09, INV-30…INV-33, INV-40…INV-44, INV-50…INV-53, INV-60…INV-65 (не покрытые профильными задачами); порядок строгости исходов: `APPROVED < COUNTER_OFFER < MANUAL_REVIEW < REJECTED`; `NEEDS_INFO` в сравнения не входит; профили `dev`/`ci`/`deep`, найденные примеры копируются в unit-регрессии.
- **Не входит:** инварианты стейт-машины и идемпотентности (в [T-251](T-251-application-state-machine.md), [T-203](T-203-idempotency-keys.md), [T-278](T-278-outbox-relay.md)).
