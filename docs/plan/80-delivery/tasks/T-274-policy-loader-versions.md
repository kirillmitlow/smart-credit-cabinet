## Цель

`api` при старте читает `policy/vN.yaml`, проверяет по схеме, считает хеш канонической формы и регистрирует версию в `policy_versions`; невалидный файл — `api` не стартует.

## Входит / не входит

- **Входит:** чтение файла (в `pipeline`, не в ядре), канонизация (ключи по алфавиту, без пробелов), SHA-256, таблица `policy_versions` (`version`, `content_hash` уникален, `content`, `effective_from`, `description`, `parent_hash`); версия применяется на момент начала прогона, оба вызова `decide()` одного запуска используют одну версию; пометка «правила обновлены» при смене версии между прогонами одной заявки.
- **Не входит:** схема и значения ([T-281](T-281-policy-schema-v1.md)).

## Критерии приёмки

- [ ] Тот же файл с другим форматированием даёт тот же хеш; правка числа — другой
- [ ] Файл без `source` у числа не проходит; грейды не покрывают 0–100 — не проходит
- [ ] Смена версии посреди прогона не смешивает версии
- [ ] Тексты причин в хеш не входят (Q-113, D-091)
- [ ] Тесты написаны и зелёные (`make check`)
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале

## Тесты
