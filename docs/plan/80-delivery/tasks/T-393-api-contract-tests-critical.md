## Цель

Обвязка фаззинга уже есть ([T-519](T-519-schemathesis-harness.md)); здесь — собственные тесты на критичное (формат ошибок, идемпотентность, права) и то, без чего Schemathesis не пройдёт по защищённым ручкам: вход, данные, фильтры состояния (D-088, Q-103).

## Входит / не входит

- **Входит:** фикстуры для Schemathesis: аутентифицированные сессии двух зон, заготовленные заявки, исключения/фильтры для ручек, зависящих от состояния; единый тест `problem+json`, тест перечня ручек, ответ соответствует схеме на сценарии каждой персоны.
- **Не входит:** oasdiff и Spectral в CI ([T-511](T-511-ci-contracts-security-notices.md)); конфигурация самого Schemathesis ([T-519](T-519-schemathesis-harness.md)).
