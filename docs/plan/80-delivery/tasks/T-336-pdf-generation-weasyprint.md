## Цель

При принятии предложения фоновая задача создаёт неизменяемые PDF с хешем: кредитный договор, график, договор поручительства (по одному на поручителя), заявление на открытие счёта (не-клиентам). На каждом листе «ДЕМО. Синтетический документ, юридической силы не имеет».

## Входит / не входит

- **Входит:** HTML-шаблоны и CSS, шрифты PT Sans (OFL) в репозитории, `THIRD_PARTY_NOTICES`; задача `documents.render_contract`, версия шаблона в `documents.template_version`, SHA-256; числа графика берутся из той же функции [T-282](T-282-money-annuity-schedule.md), что экран и калькулятор; `contract_uid` стабилен; системные библиотеки (Pango/Cairo) в Dockerfile образа `api` (образ собирает [T-215](T-215-api-dockerfile.md)).
- **Не входит:** подпись ([T-263](T-263-contract-signing.md)); оферта ([T-340](T-340-offers-variants-accept.md)).

## Критерии приёмки

- [ ] Тест по тексту PDF: содержит сумму, ставку, номер заявки и ИНН
- [ ] Тест «график PDF = график на экране = калькулятор» до рубля
- [ ] Один документ на принятие; правка условий = новая версия и новые подписи
- [ ] Генерация одного документа 0,3–1 с (замер)
- [ ] Тесты написаны и зелёные (`make check`)
