## Цель

Один общий слой для всех адаптеров: синхронный `httpx.Client`, таймауты по системам, повторы по правилам, сквозной `X-Request-Id` и запись каждой попытки в `integration_calls`. Недоступность — это результат, а не исключение.

## Входит / не входит

- **Входит:** таймауты из [50-08](../../50-architecture/08-integration-adapters.md) с множителем `INTEGRATION_TIMEOUT_SCALE`; `tenacity`: повторы только `GET` и `POST` с ключом; паузы от 0,3 с с полным разбросом; повод повтора: обрыв, таймаут, `502/503/504`, `429` с `Retry-After` до 5 с, `409 IDEMPOTENCY_IN_PROGRESS` (не тратит попытку); без повтора: прочие `4xx`, `404`, `422`, `IDEMPOTENCY_KEY_REUSED` (ERROR в лог); результат `Ok(data, snapshot_meta)` или `SourceUnavailable(system, reason)`; причины `TIMEOUT`, `HTTP_5XX`, `CIRCUIT_OPEN`, `SCHEMA_ERROR`; таблица `integration_calls` (попытка, код, длительность, замаскированный ИНН) отдельной короткой транзакцией, ошибка записи не ломает вызов.
- **Не входит:** предохранитель ([T-231](T-231-circuit-breaker.md)); кэш ([T-237](T-237-cached-vs-fresh-gateway.md)); конкретные адаптеры ([T-232](T-232-adapter-registry.md)…[T-236](T-236-adapter-bank-core-write.md)).

## Критерии приёмки

- [ ] Тест на `respx`: для каждой строки таблицы повторов — ожидаемое число попыток и итог
- [ ] Ответ, не прошедший схему, даёт `SourceUnavailable(SCHEMA_ERROR)` без падения
- [ ] Сумма всех попыток одного вызова не превышает таймаут шага конвейера
- [ ] В журнале ИНН замаскирован, тел запросов и ответов нет
- [ ] Вызов потокобезопасен (будет использоваться пулом из 4 потоков)
- [ ] Тесты написаны и зелёные (`make check`)
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале

## Тесты

unit на respx: повторы, паузы, коды; интеграционный: запись `integration_calls`.

## Заметки для реализации

- Только `GET` и `POST` с `Idempotency-Key` повторяются ([50-08](../../50-architecture/08-integration-adapters.md)).
- Пул потоков для параллельных вызовов — в `pipeline` ([T-272](T-272-pipeline-collect-sources.md)), не здесь.
