## Цель

Жюри проверяет прототип само (D-064). Сценарий из [80-07](../07-jury-self-check.md) превращается в раздел README, шаги которого совпадают с демо-панелью и реальными экранами.

## Входит / не входит

- **Входит:**
  - Раздел «Самопроверка за 20–30 минут»: шаги из [80-07](../07-jury-self-check.md) с реальными названиями кнопок и статусов (сверка с [60-06](../../60-frontend/06-ux-writing.md) и интерфейсом), с живыми ссылками (`localhost:8080`, `/demo`, Swagger)
  - Сверка порядка шагов с демо-панелью ([60-01](../../60-frontend/01-app-structure.md), 60-05): README ссылается на панель по пунктам
  - Таблица «что должно быть → что видно», блок «как сбросить», «как уронить БКИ», «как создать свою компанию»
  - Блок «если что-то не так» (топ-5 ситуаций)
- **Не входит:**
  - Репетиция сценария ([T-533](T-533-jury-rehearsal.md))

## Критерии приёмки

- [ ] Каждый шаг можно выполнить на стенде буквально по тексту; пройден хотя бы одним человеком не из разработки
- [ ] Сумма времени шагов укладывается в 20–30 минут
- [ ] Названия кнопок и статусов совпадают с интерфейсом
- [ ] ИНН персон и ожидаемые исходы совпадают с таблицей, сгенерированной [T-531](T-531-readme-generated.md)
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)

## Тесты

Проверка репетицией ([T-533](T-533-jury-rehearsal.md)) и полной сверкой с экранами.

## Заметки для реализации

- Ожидаемые суммы, платежи и ставки берите из [30-17](../../30-decisioning/17-persona-walkthrough.md) (например, Соколова: 500 000 ₽, 12 мес., ставка 21,5%, платёж 46 677 ₽) и сверяйте с экраном; расхождение — вопрос, а не правка текста «на глаз».
