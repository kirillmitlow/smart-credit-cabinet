## Цель

Клиент видит три главных причины (или два лучших фактора при одобрении) и до трёх конкретных рычагов («меньше сумма», «дольше срок», «залог», «подтвердить выручку», «погасить долг», «подождать»).

## Входит / не входит

- **Входит:** таблица вклада по девяти факторам: значение, баллы, максимум, недобор; клиенту — до 3 недоборов > 50% максимума, при `APPROVED` — до 2 лучших; рычаги из перебора встречных: меньше сумма, дольше срок, другой продукт, залог (пересчёт с LGD 35%), поручитель, подтвердить выручку (показывается, только если нужное ≤ 1,5 × текущей), погасить долг, подождать; кнопки блока возвращают заявку в работу (`COUNTER_OFFER → CHECKING`).
- **Не входит:** экран ([T-423](T-423-web-outcome-counter-offer.md)).
