## Цель

Первый коммит кода: пустые каталоги и общие правила, на которые ложатся все остальные задачи. Оба агента сразу знают, куда класть файл и как называть ветку.

## Входит / не входит

- **Входит:**
  - Каталоги `api/`, `web/`, `mocks/`, `deploy/`, `scripts/`, `docs/api/`, `docs/architecture/`, `docs/data-model/`, `.github/` с пустыми заглушками-`README`-комментариями (без отдельных README внутри модулей)
  - `.gitignore` (уже содержит `.env`, `node_modules`), `.gitattributes` (`* text=auto eol=lf` и `eol=lf` для `*.sh`, `Dockerfile`, `*.yml`: защита от CRLF у Windows-участников), `.editorconfig`, `.python-version` (3.13), `.nvmrc`
  - `Makefile`: `up`, `down`, `check`, `test`, `fmt`, `openapi`, `reset` (команды пока вызывают заглушки, наполняются по мере появления кода); жюри Makefile не нужен (D-064)
  - `.github/PULL_REQUEST_TEMPLATE.md` с чек-листом [определения готовности](../04-definition-of-done.md) и полем «Задача T-NNN»
  - Короткий раздел «Код» в `AGENTS.md` (не более ~30 строк): как поднять стенд, три команды, карта папок, три запрета, ссылка на [80-04](../04-definition-of-done.md)
- **Не входит:**
  - Конфигурация линтеров ([T-501](T-501-linters-precommit.md)), compose ([T-502](T-502-compose-main.md)), CI ([T-509](T-509-ci-skeleton.md))

## Критерии приёмки

- [ ] Структура папок соответствует таблице 50-03; `git status` чист после `make check` на пустом каркасе
- [ ] `.gitattributes` задаёт LF для shell-скриптов и Docker-файлов (Windows не ломает запуск)
- [ ] `make up`, `make down`, `make check` существуют и дают понятное сообщение, пока нет кода
- [ ] `AGENTS.md` содержит раздел «Код» не длиннее ~30 строк и не дублирует документы плана
- [ ] Шаблон PR содержит поля: задача, что сделано, как проверить, чек-лист готовности
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)

## Тесты

Проверка вручную и скриптом `check-docs` ([T-522](T-522-check-docs-links.md)): ссылки в `AGENTS.md` живы.

## Заметки для реализации

- Первым коммитом кода — каркас, как велит 50-03; остальное ложится в готовые рельсы.
- Правка `AGENTS.md` — одна из немногих правок общих файлов: делается этой задачей и больше не повторяется без нужды.
- Из-за `eol=lf` Windows-участники не должны получить CRLF в `entrypoint.sh`; проверка на Windows — [T-536](T-536-windows-check-pack.md).
