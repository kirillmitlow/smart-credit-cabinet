## Цель

Все статусы, шаги таймлайна, ошибки по `code`, пустые состояния, подсказки к терминам, демо-пометки и тексты уведомлений написаны единым тоном: что случилось → почему → что делать дальше.

## Входит / не входит

- **Входит:** шесть шагов таймлайна, тексты ошибок для каждого `code` из [50-07](../../50-architecture/07-api-design.md), пустые состояния, тон отказа, подсказки к терминам (овердрафт, залог, переплата…), тексты уведомлений из [20-06](../../20-process/06-notifications.md); тест полноты: для каждого статуса, `code` и ключа уведомления есть текст; клиентских формулировок с запрещёнными словами нет.
- **Не входит:** тексты причин решения (приходят из снимка, [T-298](T-298-explanations-text-catalog.md)).
