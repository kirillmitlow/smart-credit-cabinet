## Цель

Из параметров компании и людей получаются полные реквизиты: ИНН, ОГРН, КПП, ФИО, даты рождения, директор и учредители. Генерация детерминирована по `code`, поэтому тесты и переприменение дают те же данные.

## Входит / не входит

- **Входит:**
  - `expand.py`, часть «identity»: форма (`IP`/`LLC`/`JSC`/`SELF_EMPLOYED`), название, статус, ОКВЭД, регион, возраст бизнеса (`ageMonths` → дата регистрации при каждом применении), недостоверный адрес и признак исключения из ЕГРЮЛ
  - Люди: директор, учредители (сумма долей 100% у ООО, пусто у АО), владелец (учредитель с наибольшей долей; у ИП — сам предприниматель, у АО нет), ФИО из встроенных списков, возраст директора 25–65
  - Seed берётся из `code` сценария; уникальность ИНН по базе сценариев
  - Результат — «развёрнутые данные» (`expanded`) в частях, нужных registry, bank-core (комплаенс) и bki (люди как отдельные субъекты)
  - `POST /scenarios/preview` возвращает развёрнутые данные без сохранения
- **Не входит:**
  - Финансы ([T-121](T-121-mocks-expand-finance-basic.md), [T-122](T-122-mocks-expand-finance-advanced.md)), кредитная история ([T-123](T-123-mocks-expand-bki-basic.md), [T-124](T-124-mocks-expand-bki-advanced.md)), прочее ([T-125](T-125-mocks-expand-other-systems.md)), проверки согласованности ([T-126](T-126-mocks-consistency-rules.md))

## Критерии приёмки

- [x] Два вызова с одним `code` и одним «сегодня» дают побитово одинаковые данные
- [x] КПП начинается с тех же 4 цифр, что ИНН и код налоговой в карточке; год в ОГРН равен году регистрации
- [x] Если задан `ogrn`, дата регистрации должна быть абсолютной и совпасть с годом ОГРН, иначе `422`
- [x] У ИП и самозанятого нет КПП, директора и учредителей; у АО нет учредителей
- [x] Владелец определяется по правилу (наибольшая доля; при равных — первый в списке)
- [x] Тесты написаны и зелёные
- [x] Документация и OpenAPI обновлены, если менялся контракт
- [x] Запись в журнале

## Тесты

Unit-тесты на детерминизм, на каждую форму, на правила ОГРН/КПП и владельца; property: сумма долей 100%, ИНН уникальны на пачке 1000 сценариев.

## Заметки для реализации

- Возраст «3 месяца» у «Быстрого старта» должен быть таким и в день защиты, и через полгода: даты считаются при каждом применении от `APP_TODAY`.
- Не вызывайте `random` без seed; для тестов фиксируйте и месяц «сегодня».

## Реализация B, 21.10.2026

- [PR #20](https://github.com/kirillmitlow/smart-credit-cabinet/pull/20) влит в `main` 21.10.2026 (`b6678dd`): все проверки CI зелёные, пользователь отдельно разрешил изменение API по D-098. T-120 завершена.
- `expand.expand(spec, today, reserved_inns)` — чистая функция; `service.preview` читает занятые ИНН компаний и людей, исключая собственный сценарий. Номера в предпросмотре не резервируются; конкурентная запись относится к T-127.
- Возвращаются `identity` (люди, директор, учредители, владелец и `subjectRefs`) и `registry` (готовое админ-тело без банкротств). Позднейшие T-123/T-125 используют ссылки и людей для БКИ и комплаенса, не создавая новые личности.
- `ref` или одинаковый ИНН объединяют человека в нескольких ролях. Явные ФИО/даты не могут противоречить друг другу. У ООО без списка учредителей директор становится единственным учредителем; незаданные доли делят остаток до 100%.
- Пресет перекрывается явными параметрами; абсолютная дата удаляет унаследованный `ageMonths`. Только синтетические ИНН/ОГРН региона `00`; `regionCode` карточки может быть другим.
- Технические значения при отсутствии параметров и пресета: возраст 36 месяцев, статус `ACTIVE`, ОКВЭД `47.19`, регион `00`, капитал организации 10 000 ₽; название и ФИО из встроенных списков. Форму обязательно задаёт автор (D-101).
- Без `code` предпросмотр берёт seed из хеша параметров. Для совпадения с будущим применением передавайте явный `code`: создание без кода выдаёт новый `custom-*`.
- Предпросмотр пока не рассчитывает финансы/БКИ и не применяет сценарий к мокам. Создание остаётся `PENDING` до T-127.
- Снимок OpenAPI: `docs/api/mock-scenarios.openapi.yaml` (JSON, допустимый YAML 1.2), тест сверяет его с `create_app(Settings(mock_role="scenarios", database_url=None)).openapi()`. `make openapi` пока заглушка T-543; общий генератор пяти ролей остаётся T-139.
