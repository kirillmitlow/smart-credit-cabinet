## Цель

Файл `THIRD_PARTY_NOTICES.md` — обязательный артефакт (RQ-16). Автоматическая часть строится из lock-файлов, ручная описывает модели, датасеты, шрифты, иконки и смоделированные интеграции.

## Входит / не входит

- **Входит:**
  - Скрипт `scripts/build_notices.py`: Python-зависимости `api`, `mocks`, `nlu` (из `uv.lock`, лицензии через `pip-licenses`), фронт (из lock-файла `pnpm`), базовые образы Docker; таблица «компонент, версия, лицензия, где используется»; тексты лицензий в `licenses/`
  - Ручной раздел: модель (имя, ревизия, лицензия, ссылка, SHA-256 из `models.lock`), обучающие данные (формулировка «см. карточку модели», не заявляем больше, чем знаем), синтетические тестовые наборы, шрифты (например PT Sans, OFL) и иконки, оговорка RQ-51/RQ-57 «без платных и закрытых лицензий»
  - Раздел «Смоделированные интеграции» — таблица из раздела 12 спецификации моков + список того, что не моделируем (ФССП, арбитраж, реестр залогов, МЧД)
  - Задание `notices` в CI сравнивает сгенерированный файл с закоммиченным (подключает [T-511](T-511-ci-contracts-security-notices.md))
  - Проверка запрещённых лицензий (некоммерческие, «только для исследований»): сборка падает
- **Не входит:**
  - Выбор модели (T-001 и последующие решения)

## Критерии приёмки

- [ ] `THIRD_PARTY_NOTICES.md` содержит все зависимости из lock-файлов с лицензиями и версиями
- [ ] Ручной раздел заполнен: модель, датасеты, шрифты, иконки, смоделированные интеграции
- [ ] Добавление зависимости без перегенерации файла ломает задание `notices`
- [ ] Лицензия Redis (версия 7.2 или иная) указана корректно; решение о версии записано, если меняется
- [ ] Лицензия выбранной модели переписана с карточки в день сдачи, а не из таблицы-кандидата
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)

## Тесты

Unit-тест генератора на фиктивных lock-файлах; контроль в CI.

## Заметки для реализации

- Redis 8 вышел под AGPLv3, 7.4 — под ограничивающими лицензиями, свободная ветка 7.2; если это смутит, замена — решение владельца 50-02, не этой задачи.
- Модели в образ вшиты, поэтому в файле должны быть имя, ревизия и хеш.
