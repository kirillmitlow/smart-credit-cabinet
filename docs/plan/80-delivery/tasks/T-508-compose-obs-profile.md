## Цель

Отдельный профиль наблюдаемости с готовым дашбордом (Q-065: Grafana после основного). Показывает критерию «Enterprise» метрики, но не входит в основной сценарий.

## Входит / не входит

- **Входит:**
  - `--profile obs`: Prometheus (конфиг опроса `api`, `worker`), Grafana с провиженингом источника и одним дашбордом (скорость решений, ошибки адаптеров, состояние предохранителей, очередь)
  - Пароль Grafana из `GRAFANA_ADMIN_PASSWORD`; порты только на `127.0.0.1`
  - Лимит памяти ≈ 450 МБ; в README отметка, что `ai` и `obs` одновременно на ПК жюри не включаем
- **Не входит:**
  - Метрики внутри `api` (задачи `api`)
  - Flower (Q-056)
