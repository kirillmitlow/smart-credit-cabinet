## Цель

Дополнения финансового генератора, без которых не получить «Зарю» (сезонность), `t-mismatch` (расхождение 40%) и `t-anomaly` (накачка оборотов), а также честные ответы на вопросы жюри о трендах.

## Входит / не входит

- **Входит:**
  - `revenueTrend` (`GROWTH`/`STABLE`/`DECLINE` и `trendPercent`), `seasonality` (`NONE`/`AGRO`/`RETAIL_Q4`)
  - `statementsMismatchPercent`: строка 2110 занижается относительно оборотов — единственное разрешённое нарушение сверки
  - Число плательщиков по ОКВЭД (`counterpartiesIn`: 1–3 для розницы и общепита, 3–12 для сельского хозяйства, по числу выручки для остальных; `counterpartiesOut` 10–40)
  - Лимиты спецрежимов (АУСН, УСН, патент) в настройках и их проверка при создании сценария
  - Ряд `t-anomaly` по 30-17: 18 месяцев, 15 мес. по 5 000 000, затем 07–09.2026 по 9 000 000 (остаток 15%); окно 18, а не 24 месяца выбрано сознательно (иначе сезонное исключение подавит накачку)
  - Сезонный ряд Зари по формуле из 30-17: `incomingNetRub(m) = 650 000 000 / 12 × (1 + 0,6 × sin(2π (m − 6) / 12))`, округление до 1 ₽
- **Не входит:**
  - Новые формулы ядра (они в 30-02, 30-17 лишь проверяет)

## Критерии приёмки

- [ ] Сезонный агро-сценарий даёт обороты с выраженными пиками и среднее ≈ заданному
- [ ] `statementsMismatchPercent: 40` даёт отчётность на 40% ниже оборотов и не нарушает остальные правила
- [ ] Сценарий с выручкой выше лимита АУСН/патента отклоняется `422` с названием режима
- [ ] Тренд `DECLINE` с `trendPercent` даёт убывающий ряд оборотов
- [ ] Остальные правила сверки из [T-121](T-121-mocks-expand-finance-basic.md) продолжают выполняться
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)

## Тесты

Unit- и property-тесты; фиксированные снимки для агро-сезонности и расхождения 40%.

## Заметки для реализации

- Значения лимитов режимов нужно сверить с законодательством перед сдачей (вопрос Н-3 в спецификации); лежат в настройках.
- `statementsMismatchPercent: 40` даёт ядру расхождение 66,7% (знаменатель — отчётность, 30-17): это не ошибка, а отметка в описании сценария.
