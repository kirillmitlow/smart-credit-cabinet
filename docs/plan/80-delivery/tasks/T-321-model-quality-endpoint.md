## Цель

Андеррайтер видит светофоры и таблицу грейдов синтетического отчёта прямо в продукте (Could).

## Входит / не входит

- **Входит:** `GET /backoffice/model-quality` отдаёт сохранённый JSON отчёта без пересчёта; пометка «синтетический портфель» в ответе.
- **Не входит:** фронт страницы (не планируется).
