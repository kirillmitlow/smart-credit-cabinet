## Цель

Клиент получает код (в демо — на экране плашкой «в реальном продукте придёт SMS») и входит; если у него несколько компаний — выбирает активную.

## Входит / не входит

- **Входит:** кнопка «Получить код», плашка с кодом только в демо, поле на 6 цифр, остаток попыток и время жизни; ошибки: неверный код (остаток), истёк («Получить новый»), блок (`RATE_LIMITED`); экран «Выбор компании» (пропускается при одной), `Сменить компанию` в шапке.
- **Не входит:** демо-вход банка (в [T-434](T-434-web-demo-panel-base.md)).

- [ ] Плашка кода не показывается вне демо

- [ ] После входа открывается главная или адрес возврата
- [ ] Тесты написаны и зелёные (`make check`)
- [ ] Документация и OpenAPI обновлены, если менялся контракт
