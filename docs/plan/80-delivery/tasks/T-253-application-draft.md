## Цель

Автосохранение черновика без потери данных между вкладками: клиент шлёт `version`, расхождение даёт `VERSION_CONFLICT`; ответы мастера и анкета лежат в `applications.draft`.

## Входит / не входит

- **Входит:** `PATCH /applications/{id}/draft` (слияние по шагам), проверка допустимости по статусу `DRAFT`; `409 VERSION_CONFLICT` с актуальной версией; серверная проверка полей шагов: ИНН (контрольная сумма), границы суммы и срока продукта, обязательные поля шага 3; метка происхождения ответа мастера («Из вашего текста») хранится рядом с ответом.
- **Не входит:** отправка ([T-254](T-254-application-submit.md)); залог и поручитель ([T-257](T-257-collateral-guarantor-in-application.md)).

## Критерии приёмки

- [ ] Две вкладки: проигравшая получает `VERSION_CONFLICT` и может перечитать черновик (тест)
- [ ] Сумма и срок вне рамок продукта → `VALIDATION_ERROR` с путём к полю
- [ ] Черновик чужой компании недоступен (`404`)
- [ ] Текст клиента из «своими словами» не попадает в логи
- [ ] Тесты написаны и зелёные (`make check`)
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
