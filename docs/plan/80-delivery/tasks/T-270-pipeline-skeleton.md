## Цель

Один запуск конвейера на версию заявки: идемпотентные шаги с сохранёнными контрольными точками, аренда от двойного исполнения, переход `SUBMITTED → CHECKING` и события шагов для таймлайна.

## Входит / не входит

- **Входит:** `pipeline_runs` (`run_key` уникален, `trigger`, `current_step`, `locked_until`, `attempts`), задача `pipeline.run(version_id)`; шаги как отдельные функции (полнота, источники, БКИ, решение, сохранение); повторный запуск пропускает выполненные; аренда `locked_until`, продление во время работы, второй экземпляр тихо выходит; события `STEP` в журнал после каждого шага (идёт подшагами в таймлайн); бизнес-сбой источника не исключение (ожидаемый результат `SourceUnavailable`).
- **Не входит:** сбор источников ([T-272](T-272-pipeline-collect-sources.md)); БКИ ([T-273](T-273-pipeline-bureau-step.md)); сохранение решения ([T-275](T-275-decision-persistence.md)); сторож ([T-271](T-271-pipeline-reaper-lease.md)).
