## Цель

Проверка на чистой Windows-машине (D-009) делается людьми из команды: агенты готовят им короткую инструкцию, чек-лист и форму ответа. Задача агента — подготовка и разбор результата.

## Входит / не входит

- **Входит:**
  - Инструкция на русском для человека без опыта в Docker: установка Docker Desktop (WSL2), выдача памяти Docker, клонирование, `docker compose up`, открытие страницы, шаги самопроверки (сокращённые)
  - Чек-лист «что должно получиться» и форма отчёта: версия Windows, RAM, версия Docker, время сборки, ошибки (скриншот/текст), шаги, которые не удались
  - Список известных проблем Windows: CRLF в скриптах, пути длиннее 260 символов, антивирус, занятые порты, `localhost` в WSL2, Git Bash против PowerShell
  - Разбор присланных отчётов: каждая проблема — правка README/конфигурации/вопрос
- **Не входит:**
  - Проверка на Windows силами команды (D-009); исправление найденных проблем (отдельные задачи)

## Критерии приёмки

- [ ] Инструкция не требует `make`, WSL-команд сверх установки Docker Desktop и знаний git, кроме клонирования
- [ ] Форма отчёта собирает версии и время, достаточные для диагностики
- [ ] Минимум один человек из команды выполнил проверку на Windows-машине до заморозки; результат разобран
- [ ] Найденные проблемы с влиянием «блокирует» исправлены до V10
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)

## Тесты

Тест = выполнение людьми; агент проверяет, что скрипты не содержат CRLF и лишних зависимостей.
