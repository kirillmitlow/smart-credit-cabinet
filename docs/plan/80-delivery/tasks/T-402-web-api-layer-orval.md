## Цель

Экраны ходят в `api` только через сгенерированные хуки TanStack Query; общий обработчик добавляет служебные заголовки и превращает `problem+json` в `AppError` (D-080).

## Входит / не входит

- **Входит:** конфиг orval по `docs/api/api.openapi.yaml`, `make openapi` перегенерирует клиент в `src/api/generated/` ([T-543](T-543-make-openapi-all.md)), хуки и типы; общий fetch-обработчик: `X-Request-Id` (новый на запрос), `X-CSRF-Token` из cookie для не-GET, `Idempotency-Key` на действие пользователя (`useActionKey`: ключ создаётся при действии, сохраняется при повторе, сбрасывается после успеха); `AppError` с `code`, `status`, `requestId`, `errors[]`; обработка `401` (на вход), `409 VERSION_CONFLICT`, `429` с `Retry-After`, `503`; генерация обработчиков MSW из схемы для тестов.
- **Не входит:** тексты ошибок ([T-405](T-405-web-texts-dictionary-infra.md), [T-437](T-437-web-texts-full-60-06.md)); SSE ([T-407](T-407-web-use-event-stream.md)).

## Критерии приёмки
