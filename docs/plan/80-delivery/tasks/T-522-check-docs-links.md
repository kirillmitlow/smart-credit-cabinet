## Цель

Документы плана не должны ломаться молча: битые ссылки, пропавшая шапка и неразобранные диаграммы ловятся автоматически (50-03).

## Входит / не входит

- **Входит:**
  - `scripts/check_docs.py`: относительные ссылки живы (файлы и якоря), у каждого документа есть обязательная шапка из стандарта, mermaid-блоки разбираются
  - Подключение к заданию `docs` ([T-509](T-509-ci-skeleton.md)) и к `make check`
  - Понятный отчёт: файл, строка, что не так
- **Не входит:**
  - Сверка каталога `TS-NNN` и меток тестов ([T-523](T-523-check-docs-ts-labels.md))

## Критерии приёмки

- [ ] Скрипт находит искусственно битую ссылку и пропущенную шапку
- [ ] На текущем состоянии репозитория скрипт даёт 0 ошибок (или список исправлений приложен)
- [ ] Время работы меньше 30 секунд
- [ ] Нет сетевых запросов (внешние ссылки не проверяются)
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)
