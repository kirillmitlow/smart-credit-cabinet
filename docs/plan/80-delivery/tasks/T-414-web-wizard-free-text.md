## Цель

Клиент пишет как думает, мастер показывает «Мы поняли так»: ответы с пометкой «Проверьте» подтверждаются кликом (D-094); любой ответ меняется одним кликом. Без модели поле скрыто.

## Входит / не входит

- **Входит:** поле, примеры-подсказки под ним, кнопка «Заполнить», ожидание до 3 с с индикатором, текст «Текст обрабатывается на сервере этого стенда и никуда не отправляется»; экран «Мы поняли так»: текст клиента вверху, ответы с метками «Из вашего текста»/«Проверьте», непонятое спрашивается кнопками; поле скрыто при `nluAvailable=false`; при ошибке — «Давайте ответим кнопками», без технических слов.
- **Не входит:** сам разбор (бэкенд [T-245](T-245-wizard-parse-text.md), [T-380](T-380-nlu-service.md)).
