## Цель

Задание, которое доказывает главное: поднятый с нуля стенд проходит персон. В PR — сокращённый набор (smoke + `sokolova`, `snabkontrakt`, `romashka`), на `main` и перед тегом — полный (все 9 персон).

## Входит / не входит

- **Входит:**
  - Шаги: `docker compose up --wait` на чистом раннере, `scripts/smoke.sh`, `bru run` по коллекциям, персоны по API, контрактные тесты адаптеров против живых моков, Schemathesis ([T-519](T-519-schemathesis-harness.md)), Playwright (сокращённый/полный набор)
  - Сбор артефактов при падении: логи контейнеров, трассы и видео Playwright, отчёты; сброс данных в начале каждого шага
  - Замер `docker stats` после прохода персон: сумма ≤ 4 ГБ, иначе красное (D-066)
  - Ограничение по времени задания; Chromium только; один повтор Playwright
- **Не входит:**
  - Хаос и нагрузка ([T-513](T-513-ci-nightly-full.md))
  - Сами тесты персон ([T-517](T-517-personas-api-harness.md), [T-518](T-518-playwright-harness.md))

## Критерии приёмки

- [ ] В PR сокращённый набор укладывается в бюджет и блокирует слияние; на `main` идёт полный
- [ ] Красный smoke или красный замер памяти делают `ci-ok` красным
- [ ] Артефакты падения (логи, трассы) скачиваются и достаточны для диагностики
- [ ] Персоны сбрасываются перед прогоном (`apply` для моков и сброс данных персоны в `api`)
- [ ] Время сокращённого набора записано (ориентир ≤ 15 минут всего PR)
- [ ] Тесты написаны и зелёные
- [ ] Документация и OpenAPI обновлены, если менялся контракт
- [ ] Запись в журнале
- [ ] Выполнено [определение готовности](../04-definition-of-done.md) (линтеры, PR по шаблону, статус задачи обновлён)

## Тесты

Проверка на тестовых PR: зелёный, сломанная персона, остановленный мок.

## Заметки для реализации

- Чаос-тесты запускаются отдельным заданием и по одному: режим мока глобален ([T-513](T-513-ci-nightly-full.md)).
- Если Docker-кэш Actions не помогает, собирайте образы один раз и передавайте артефактом между заданиями.
