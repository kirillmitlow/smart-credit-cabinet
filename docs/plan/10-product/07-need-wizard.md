# Мастер подбора: от задачи клиента к продукту

| | |
|---|---|
| Статус | DRAFT |
| Владелец | Агент A |
| Зависит от | D-011, D-017, D-060, [10-06](06-product-catalog.md) |
| Обновлено | 21.10.2026 |

Клиент не знает слов «овердрафт» и «кредитная линия», зато точно знает, **зачем ему деньги**. Мастер спрашивает про ситуацию бизнеса, а продукт выбирают наши правила.

## Принципы

1. Один вопрос на экран, крупные карточки с примерами. 4–5 вопросов, меньше минуты.
2. Не спрашиваем то, что знаем сами: компания, отрасль, возраст, выручка (если счёт у нас).
3. Везде есть «Не знаю». Тогда помогаем подсказкой или подбираем без этого ответа.
4. Вопросы ветвятся по ответу на первый.
5. Ответы переходят в заявку, второй раз ничего не вводится.
6. Можно вернуться и поменять ответ, результат пересчитается.

## Вход в мастер

Два способа, результат один и тот же:
- **Кнопки.** Основной путь, работает всегда.
- **«Опишите своими словами»** (D-060). Модель заполняет ответы с оценкой уверенности. Сумму достаёт парсер. Где модель не уверена, мастер спрашивает кнопками. Клиент видит заполненный мастер и подтверждает. Модель продукт не выбирает.

## Вопросы (слоты)

Слоты совпадают со схемой замера моделей (T-001), чтобы результат замера подключался без переделок.

| Слот | Вопрос клиенту | Варианты | Когда задаём |
|---|---|---|---|
| `purpose` | На что нужны деньги? | Купить оборудование или транспорт · Закупить товар или сырьё · Выполнить заказ, за который заплатят позже · Перекрыть временную нехватку денег · Развить бизнес · Другое | Всегда |
| `amount_rub` | Сколько нужно? | Число. «Не знаю» → помощник: «сколько обычно закупаете в месяц?» | Всегда |
| `frequency` | Такое бывает регулярно? | Разово · Несколько раз в год | Товар, нехватка денег, заказ |
| `payback_horizon` | Когда вернутся деньги? / На сколько не хватает? | Несколько дней · Несколько недель · 1–3 мес · 3–12 мес · Больше года | Товар, заказ, нехватка, развитие |
| `gov_contract` | Это госзаказ? | Да · Нет | Заказ с оплатой позже |
| `urgency` | Когда нужны деньги? | Срочно, сегодня-завтра · В течение недели · Не горит | Всегда. Не меняет продукт, меняет порядок рекомендаций |
| `term` / платёж | Какой платёж в месяц комфортен? | 2–3 готовых варианта «срок → платёж → переплата» для этой суммы. Тот, что по силам при известной выручке, помечен | Продукты с ежемесячными платежами |
| `collateral` | Есть ли что-то в залог? | То, что покупаю · Недвижимость · Другая техника · Нет · Не уверен | Только если сумма выше порога без залога |

## Ответы → продукт

| Цель | Уточнение | Основной продукт | Альтернатива |
|---|---|---|---|
| Оборудование | Сумма ≤ 3 млн | `EXPRESS` | `INVESTMENT` |
| Оборудование | Сумма > 3 млн | `INVESTMENT` | — |
| Товар | Разово | `WORKING_CAPITAL` | `EXPRESS`, если ≤ 3 млн |
| Товар | Регулярно | `CREDIT_LINE` | `WORKING_CAPITAL` |
| Заказ с оплатой позже | Госзаказ или крупный контракт | `CONTRACT` | `WORKING_CAPITAL` |
| Заказ с оплатой позже | Регулярно | `CREDIT_LINE` | `CONTRACT` |
| Нехватка | Дни, клиент банка | `OVERDRAFT` | `EXPRESS` |
| Нехватка | Дни, не клиент | `EXPRESS` + «овердрафт станет доступен через 6 мес» | — |
| Нехватка | Недели, часто | `CREDIT_LINE` | `EXPRESS` |
| Развитие | ≤ 3 млн | `EXPRESS` | `WORKING_CAPITAL` |
| Развитие | > 3 млн | `INVESTMENT` или `WORKING_CAPITAL` по `payback_horizon` | — |
| Любая | Бизнесу < 6 мес | Путь «На запуск»: продукт только с поручительством или залогом, ручное рассмотрение | — |
| Другое | — | `EXPRESS`, если ≤ 3 млн, иначе каталог с подсказкой | — |

Каждый кандидат проходит **те же требования продукта, что и в ядре** (10-06), и предварительный расчёт `preview()`. Показываем **один основной и одну альтернативу**. У каждого: «почему подходит вам» одной фразой, примерный платёж, срок решения («за минуты автоматически» / «1–2 дня, смотрит специалист»), какие документы понадобятся.

## Как говорим с клиентом

| Не говорим | Говорим |
|---|---|
| Цель кредитования | На что нужны деньги |
| Пополнение оборотных средств | Закупить товар или сырьё |
| Кассовый разрыв | Временная нехватка денег |
| Срок кредита | За сколько хотите вернуть |
| Аннуитетный платёж | Платёж в месяц |
| Обеспечение | Залог — гарантия для банка |

Полный словарь — в 60-06.

## Как проверяем

- Таблица «ответы → продукт» становится набором unit-тестов один в один.
- e2e: каждая персона проходит мастер и получает тот продукт, который записан в 10-02.
- Юзабилити-тест: 3–5 человек вне банковской сферы проходят мастер (D-009).

## Заметки для реализации

- Таблица соответствия лежит в конфиге правил (30-13), а не в коде фронта.
- Если модель для свободного текста недоступна, поле «своими словами» скрывается. Ошибку клиенту не показываем.
