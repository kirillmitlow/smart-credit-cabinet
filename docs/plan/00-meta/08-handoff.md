## Стыки и ограничения кода

- `expand.py`: пресет + явные поля (null сохраняются) → identity → finance → bki → other. Чистая функция, без записи. `service.preview` читает занятые ИНН и передаёт БИК приложения.
- `identity.subjectRefs` связывает company/director/owner/founder:<ref> с ИНН. Людей повторно не генерировать. У ИП компания и владелец — один человек; личная кредитная история может быть старше бизнеса.
- `bki_expand` возвращает `bki:[{inn,body}]` и `bankLoans`. `other_expand` объединяет свои кредиты в `bankCore`, создаёт одинаковые дела ЕФРСБ/БКИ и `bankSubjects` для реальных фактов комплаенса.
- В T-127 полностью пустые тела пропускать: пустой PUT АБС не создаёт ресурс. Чистые люди получают CLEAR без записи. У самозанятого может быть только НПД.
- `raw` пока не применяется; общих правил T-126 нет. POST создаёт PENDING, не применяя данные в другие моки. Половинчатый результат нельзя объявлять V2.
- 1400/2330 пока нулевые; нужно согласование с БКИ. В bank-core outstandingRub пока отражает исходную сумму, погашения не моделируются.
- Финансовый ряд общий для оборотов/отчётности; налоги и НДС — настройки с первичными источниками. D-105 исправляет ПСН-2026 на 20 млн. Тренд геометрический, дефолт 10% — допущение. Точные 650 млн Зари и 18 месяцев t-anomaly задаются raw, без условий по code.
- Будущий T-280 должен стать общим источником кредитной математики; сейчас чистые формулы в scenarios/credit_math.py. `make openapi` ещё заглушка T-543; снимок scenarios есть, все роли — T-139.
