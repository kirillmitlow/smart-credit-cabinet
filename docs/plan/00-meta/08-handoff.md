## Как стыкуется код

- `expand.py`: resolved_spec объединяет пресет и явные параметры, сохраняя явные null; абсолютная дата удаляет возраст пресета. Pureexpand принимает today/reservedINNs/ScenarioSettings. Сейчас подключены identity и finance.
- `identity.subjectRefs`: company/director/owner/founder:<ref> →ИНН; persons хранят людей. Не генерировать новых людей для БКИ/комплаенса. У ИП company=owner=один человек, его история может быть старше бизнеса; у ООО/АО история компании ограничена регистрацией.
- `bki_expand.expand_bki(resolved,identity,code,today)` →`bki:[{inn,body}]`, `bankLoans:[{inn,body:{loans:[]}}]`. В main версия T123, в ветке T124 добавлены события. CreditDefaults позволяет задать 21%/5% вне формул. Код считает свои кредиты до 1 руб., чужие до 100/1000 руб. Кредитная математика пока в scenarios/credit_math.py; будущее ядро должно иметь общий источник формул.
- `other_expand.expand_other(resolved,expanded,code,today,bank_bik)` →глубокий клон полного снимка. Объединяет bankLoans с bankCore; добавляет bankSubjects только для реальных фактов комплаенса. Единый генератор дела даёт одинаковые номер/даты дляЕФРСБ/БКИ.
- Для T127 **полностью пустые тела ролей пропускать**: пустой админ-PUT АБС не создаёт ресурс, общий админ потом отвечает 404. Чистые люди всё равно проверяются screening и получают CLEAR. Самозанятый может иметь толькоНПД.
- T121 финансы пока имеют нулевые 1400/2330; согласование долга/процентов сБКИ ещё нужно в T126/стыковке. Известное ограничение bank-core: outstandingRub без моделирования погашений отражает первоначальный amountRub. Не объявлять общую проверку согласованности выполненной.
- Raw пока не сливается, общих 30 правил нет, POST создаёт PENDING и не применяет данные в остальные моки. Атомарный откат/ежемесячное переприменение ещё не готовы.
- T122 исправляетПСН:2026=20 млн,2027=15 млн,2028+=10 млн; источникФНС вкарточке/spec. До 2026=60 млн. В global реестр нужно добавитьэкономическое уточнение(D104 свободен на момент передачи) и заменить старую заметкуН-3. Пока эта правка только вветке T122.
