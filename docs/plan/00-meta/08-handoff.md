Снимок: из `api/` выполнить `uv run python -c` с записью `json.dumps(create_app().openapi(), indent=2, ensure_ascii=False)` и переводом строки в конце в `../docs/api/api.openapi.json`. Затем `pnpm gen:api` в `web/`. На машине Кирилла pnpm нет: `npx -y pnpm@12.14.0 …` или `make -C web check PNPM="npx -y pnpm@12.14.0"`.
