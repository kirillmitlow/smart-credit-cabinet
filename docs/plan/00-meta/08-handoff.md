## Подсказки по коду и запуску

- Чистая точка входа: `mocks/app/roles/scenarios/expand.py`, `expand(spec, today, reserved_inns)`. Пресет объединяется отдельно; абсолютная дата удаляет его относительный возраст.
- `expanded.identity.subjectRefs` связывает `company`, `director`, `owner`, `founder:<ref>` с ИНН; `identity.persons` хранит данные людей. T-123/T-125 должны переиспользовать личности, а не генерировать новые. `expanded.registry` — админ-тело; банкротства туда добавит T-125.
- Без явного `code` preview использует хеш параметров; для совпадения с будущим применением нужен явный код. Без него POST создаёт новый `custom-*`.
- Уникальность при одновременном применении ещё задача T-127; preview не резервирует номера.
- `docs/api/mock-scenarios.openapi.yaml` — JSON (допустимый YAML 1.2), выгружен из FastAPI; тест сверяет с кодом. Общий `make openapi` пока заглушка T-543, генератор всех пяти ролей остаётся T-139. Есть два запроса Bruno в `docs/api/collection/mocks/own-company/`.
- На этом Mac отсутствует wrapper `uvx`, но `uv tool run` работает: для проверки использовано `make PRE_COMMIT='uv tool run pre-commit@4.7.0' check`, кеши `UV_CACHE_DIR=/private/tmp/scc-uv-cache`, `UV_TOOL_DIR=/private/tmp/scc-uv-tools`, `PRE_COMMIT_HOME=/private/tmp/scc-precommit`. Это местная особенность, Makefile не менялся.
- Docker доступен; вне песочницы `cd mocks && HYPOTHESIS_PROFILE=ci uv run pytest --cov` поднимает Postgres через Testcontainers.
