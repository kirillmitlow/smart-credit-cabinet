**Статус: подготовлена, человеком пока не выполнена.** Автоматические прогоны описаны в [отчёте](plan/reviews/B-2026-10-25-freeze-verification.md). Здесь проверяется понятность README без подсказок разработчика. Ориентир после готовности стенда — 20–30 минут; это ещё не измеренное время независимой проверки.

1. Откройте только [README](../README.md), без истории агентов и исходников.
2. На своём компьютере клонируйте репозиторий, выберите тег `submission-20261026` и выполните запуск из README. Для воспроизводимых чисел используйте `APP_TODAY=2026-10-21`. Не запускайте второй проект на занятых портах уже работающего стенда.
3. Пройдите четыре основных сценария README. Выходите из клиентского кабинета перед сменой компании. Банк открывайте в отдельной вкладке: его сессия независима.
4. В положительных случаях дойдите до выдачи и графика; в Ромашке найдите причины отказа. Для Станкопрома: оборотные 15 млн / 12 месяцев → ручное встречное 10 млн / 12 месяцев.
5. При остановке запишите номер шага, ожидаемый результат и текст на экране. Не меняйте условия ради «правильного» результата; cookie и коды подписи в отчёт не включайте.

Проверяющий, дата, ОС, браузер, SHA и прежнее участие в разработке: **не заполнено**.
