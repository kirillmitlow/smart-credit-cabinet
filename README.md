# Smart Credit Cabinet

Прототип цифрового кредитного конвейера для малого и микробизнеса (Альфа-Будущее Хакатон 2026, кейс «Умный кредитный кабинет предпринимателя»).

Кейс: [docs/case.md](docs/case.md) (текстовая версия), [оригинал в PDF](docs/Альфа_Хак_Умный_кредитный_кабинет.pdf).

## Демонстрационная подпись

Согласия отмечаются отдельно и подтверждаются одним кодом на выбранный пакет. При включённом демо-режиме код показан прямо на экране с пометкой «Демо: в реальной системе код пришёл бы по SMS». Настоящие SMS и юридически значимая электронная подпись в прототипе не используются.
